\chapter{ความเป็นมาและรากฐานทางทฤษฎี}

\section{ความเป็นมาและความสำคัญของปัญหา}
ดินในพื้นที่เกษตรกรรมของจังหวัดจันทบุรีและตราด โดยเฉพาะสวนทุเรียน มังคุด และเงาะ ประสบปัญหาการสะสมของธาตุอาหารไม่สมดุลจากการใช้ปุ๋ยเคมีในปริมาณสูงติดต่อกันเป็นเวลานาน การส่งตัวอย่างดินไปตรวจวิเคราะห์ในห้องปฏิบัติการมาตรฐานใช้เวลานาน 7 ถึง 14 วัน และมีค่าใช้จ่ายสูง ทำให้เกษตรกรขาดข้อมูลประกอบการตัดสินใจแบบทันท่วงที ส่งผลให้เกิดการสะสมของฟอสฟอรัสตกค้างที่ไม่เป็นประโยชน์ และเกิดการชะล้างไนโตรเจนลงสู่แหล่งน้ำธรรมชาติ

งานวิจัยนี้จึงมุ่งพัฒนานวัตกรรมเครื่องมือวิเคราะห์ดินแบบพกพาโดยใช้เทคนิค Visible and Near-Infrared Diffuse Reflectance Spectroscopy ร่วมกับปัญญาประดิษฐ์บนอุปกรณ์เคลื่อนที่ เพื่อให้เกษตรกรทราบปริมาณไนโตรเจนทั้งหมด (Total Nitrogen) และฟอสฟอรัสที่เป็นประโยชน์ (Available Phosphorus) ในแปลงปลูกได้ทันทีภายใน 3 วินาที พร้อมเชื่อมโยงคำแนะนำชีวภัณฑ์จุลินทรีย์ดินท้องถิ่น

\section{ทฤษฎีการสะท้อนแสงแบบกระจายและพันธะโมเลกุลในดิน}
เมื่อลำแสงตกกระทบลงบนผิวหน้าของอนุภาคดิน แสงจะเกิดการสะท้อนสองลักษณะ ได้แก่ การสะท้อนแบบสเปคิวลาร์ (Specular Reflection) ที่สะท้อนตามกฎการสะท้อนเชิงเรขาคณิต และการสะท้อนแบบกระจาย (Diffuse Reflectance) ที่แทรกซึมเข้าไปในเนื้อดินแล้วสะท้อนกลับออกมาหลังจากเกิดปฏิสัมพันธ์กับการดูดกลืนแสงของโมเลกุล

\end{figure}

ปริมาณการดูดกลืนแสงและค่าความสะท้อนสัมพันธ์ ($R_\lambda$) เป็นไปตามทฤษฎีคูเบลกา-มองค์ (Kubelka-Munk Theory) ดังสมการ

\begin{equation}
F(R_\infty) = \frac{(1 - R_\infty)^2}{2 R_\infty} = \frac{K}{S}
\end{equation}

โดย $K$ คือสัมประสิทธิ์การดูดกลืนแสง (Absorption Coefficient) และ $S$ คือสัมประสิทธิ์การกระเจิงแสง (Scattering Coefficient) ซึ่งแปรผันตามขนาดของอนุภาคดินและความชื้น

\section{การไขความกระจ่างทางวิทยาศาสตร์ ความสัมพันธ์ระหว่าง Total N และ Available P}
ในการพัฒนาแบบจำลองระยะแรก มักพบข้อสงสัยว่าเหตุใดจึงตรวจวัดค่าไนโตรเจนทั้งหมด (Total N) ได้อย่างรวดเร็ว ในขณะที่ฟอสฟอรัสที่เป็นประโยชน์ (Available P) มีความซับซ้อนและตรวจจับได้ยากกว่ามาก ข้อเท็จจริงทางฟิสิกส์สเปกโทรสโกปีอธิบายได้ดังนี้

\begin{enumerate}
    \item \textbf{ไนโตรเจนทั้งหมด (Total N)} ไนโตรเจนมากกว่า 90\% ในดินเกษตรกรรมผูกพันอยู่กับอินทรียวัตถุในดิน (Soil Organic Matter หรือ SOM) ซึ่งประกอบด้วยพันธะ C-H, N-H และ O-H อินทรียวัตถุนี้ส่งผลโดยตรงต่อค่าความมืดสว่าง (Value / Brightness) และความเข้มสีของดินอย่างชัดเจนในย่านแสงที่ตามองเห็น ($400 - 700\text{ nm}$) และย่านอินฟราเรดย่านใกล้ $850\text{ nm}$ จึงทำให้ระบบสามารถประเมินค่าทางอ้อม (Colorimetric Proxy) ได้อย่างแม่นยำแม้ใช้เพียงเซนเซอร์ RGB
    
    \item \textbf{ฟอสฟอรัสที่เป็นประโยชน์ (Available P)} ฟอสฟอรัสในดินไม่ได้เป็นเม็ดสีที่ให้ค่าสีจำเพาะต่อสายตามนุษย์ แต่มักอยู่ในรูปของสารประกอบออร์โธฟอสเฟตที่จับตัวอยู่กับสารประกอบเหล็กออกไซด์ (Iron Oxides) และอะลูมิเนียมในดินกรด การตรวจวัดฟอสฟอรัสจึงต้องการการดูดกลืนแสงในช่วงคลื่นจำเพาะ ได้แก่ $525\text{ nm}$ และย่านอินฟราเรดย่านใกล้ $940\text{ nm}$ ซึ่งเกินขอบเขตที่แสงขาวธรรมดาจะให้ข้อมูลได้โดยตรง
\end{enumerate}

\section{การควบคุมแสงรบกวน 0-Lux และเรขาคณิตเชิงแสง CIE 45°/0°}
การตรวจวัดการสะท้อนแสงในแปลงเกษตรกรรมจำเป็นต้องควบคุมสภาพแวดล้อมให้มืดสนิท (0-Lux Ambient Light) เพื่อป้องกันแสงแดดและแสงหลอดไฟภายนอกรบกวน กล่องมืด (Dark Chamber) จึงถูกออกแบบตามมาตรฐานสากล CIE 45°/0° โดยจัดตำแหน่งแหล่งกำเนิดแสงทำมุม 45 องศากับแนวตั้งฉากของผิวหน้าดิน และติดตั้งกล้องสมาร์ทโฟนไว้ที่แนวตั้งฉาก 0 องศา (Nadir Angle) การจัดมุมนี้ทำให้แสงสะท้อนผิวหน้าแบบกระจก (Specular Reflection หรือ Direct Glare) สะท้อนออกไปในทิศทาง 45 องศาฝั่งตรงข้าม ไม่เข้าสู่หน้าเลนส์กล้อง ทำให้เซนเซอร์กล้องรับเฉพาะแสงสะท้อนแบบกระเจิง (Diffuse Reflectance) ซึ่งเป็นแสงที่ทำอันตรกิริยากับพันธะเคมี สารอินทรีย์ และเม็ดสีของเนื้อดินจริง

\subsection{วงจรขับกระแสและการควบคุมสโตรบป้องกันแถบคลื่นดำ}
วงจรขับหลอด LED ใช้ไอซีขับกระแสคงที่ประเภท Buck LED Driver (เช่น AL8860 หรือ PT4115) เพื่อควบคุมความเข้มแสงให้คงที่สม่ำเสมอแม้แรงดันแบตเตอรี่จะลดลงระหว่างใช้งานภาคสนาม นอกจากนี้ เซนเซอร์ CMOS ของสมาร์ทโฟนใช้ชัตเตอร์แบบกลิ้ง (Rolling Shutter) หากควบคุมแสงด้วยสัญญาณ PWM ความถี่ต่ำ ภาพที่ได้จะเกิดแถบคลื่นมืดสลับสว่าง (Rolling Shutter Banding) ระบบจึงควบคุมการเปิด-ปิดแสงด้วยสัญญาณสโตรบกระแสตรงต่อเนื่อง (DC Continuous Pulse) ในช่วงจังหวะการบันทึกภาพ (200 ถึง 300 มิลลิวินาทีต่อแชนเนล) หรือใช้ความถี่ PWM สูงกว่า 25 kHz ขึ้นไป

\section{การวิเคราะห์เชิงเปรียบเทียบแหล่งกำเนิดแสงและการประยุกต์ใช้แฟลชสมาร์ทโฟน}
โครงการวิจัยได้ทำการศึกษาวิจัยเชิงลึกถึงความเป็นไปได้ในการใช้ไฟฉายแฟลชในสมาร์ทโฟนเป็นแหล่งกำเนิดแสง พบว่าสามารถใช้งานได้จริงในระบบพกพาต้นทุนต่ำ (NPxAI Lite) โดยมีข้อดีคือกล่องมืดไม่ต้องมีวงจรไฟฟ้าหรือแบตเตอรี่ เกษตรกรสามารถนำสมาร์ทโฟนมาประกบและสแกนได้ทันทีผ่านคำสั่งเปิดไฟฉาย (Torch Mode) ของแอปพลิเคชัน

อย่างไรก็ดี หลอดแฟลชสมาร์ทโฟนเป็นหลอด Blue LED เคลือบสารฟอสเฟอร์สีเหลือง ครอบคลุมเฉพาะแสงที่ตามองเห็น ($450 - 650\text{ nm}$) ปราศจากคลื่นย่าน NIR อีกทั้งตำแหน่งหลอดแฟลชอยู่ชิดเลนส์กล้องมาก ($5 - 12\text{ mm}$) หากส่องตรงลงไปจะเกิดแสงสะท้อนจ้า (Specular Glare) เข้าสู่เลนส์ ทีมวิจัยจึงได้ออกแบบแนวทางแก้ไขเชิงวิศวกรรมดังนี้

\begin{enumerate}
    \item \textbf{ท่อนำแสงเอียงและแผ่นกระจายแสง (Optical Light Pipe \& 45° Deflector)}
    ภายในกล่องทำท่อนำแสงเอียงรับแสงจากหลอดแฟลชแล้วหักเหให้ตกกระทบหน้าดินที่มุม 45 องศา พร้อมติดตั้งแผ่นอะคริลิกฝ้าหนา 1 mm (Diffuser) หน้าช่องแสงเพื่อเกลี่ยแสงให้เป็นลัมเบอร์เชียน (Lambertian Illumination) กระจายตัวสม่ำเสมอทั่วหน้าดิน ไร้จุดสว่างจ้า
    
    \item \textbf{การสอบเทียบแสงแบบเวลาจริงด้วยแผ่นเทียบสีขาว (Real-Time White Tile Normalization)}
    ติดตั้งแผ่นเทียบสีขาวมาตรฐาน (PTFE Tile 99\% Reflectance) ขนาด $10 \times 10\text{ mm}$ ไว้ที่ขอบภาพ เพื่อให้ระบบคำนวณชดเชยการลดทอนของแสงแฟลชจากความร้อน (Thermal Dimming) ได้แบบไดนามิก
    
    \item \textbf{การประมาณค่าด้วย Colorimetric Proxy}
    โครงข่ายประสาทเทียมจะประมาณค่าไนโตรเจนและฟอสฟอรัสทางอ้อมผ่านความเข้มข้นของอินทรียวัตถุในดิน (SOM), ความชื้น, และระบบสีดิน Munsell (Hue, Value, Chroma) ให้ความแม่นยำ $R^2 \approx 0.78 - 0.85$ ซึ่งเพียงพอสำหรับการแนะนำการใส่ปุ๋ยเบื้องต้น
\end{enumerate}

\section{แหล่งรับแสงและการปรับเทียบสีมาตรฐาน (Light Detector \& Calibration)}
แหล่งรับแสงของระบบแบ่งออกเป็น 2 ระดับ ได้แก่

\begin{enumerate}
    \item \textbf{แหล่งรับแสงหลัก (Primary Detector)} ใช้เซนเซอร์รับภาพ CMOS ในกล้องหลักของสมาร์ทโฟน (Main Wide Camera) มีฟิลเตอร์สีแบบไบเยอร์ (Bayer Color Filter Array) ทำหน้าที่รับแสงสะท้อนแบบกระจายและแปลงเป็นสัญญาณดิจิทัล โดยแอปพลิเคชัน NPxAI จะดึงภาพจากพิกัดพื้นที่สนใจ (Region of Interest: ROI) ขนาด $120 \times 120\text{ pixels}$ กึ่งกลางช่องมองภาพ มาคำนวณการดูดกลืนแสงและปริภูมิสี
    
    \item \textbf{แหล่งรับแสงเสริม (Auxiliary NIR Photodetector)} เนื่องจากเลนส์กล้องสมาร์ทโฟนทั่วไปมีแผ่นกรองแสงอินฟราเรด (IR Cut-off Filter) ติดตั้งอยู่หน้าเซนเซอร์ ทำให้ความไวแสงลดลงที่ความยาวคลื่นเกิน $750\text{ nm}$ ในรุ่น NPxAI Pro จึงสามารถติดตั้งเซนเซอร์สเปกตรัม Vis-NIR ขนาดจิ๋ว (เช่น AS7263 หรือ OPT101 Silicon Photodiode) เสริมไว้ข้างเลนส์กล้อง เพื่อตรวจรับคลื่น $850\text{ nm}$ และ $940\text{ nm}$ ได้โดยตรง
\end{enumerate}

ค่าการสะท้อนแสงสัมพัทธ์ของดินคำนวณเทียบกับแผ่นเทียบสีขาวมาตรฐาน ($\text{BaSO}_4$ หรือ PTFE $99\%$) ดังสมการ

\begin{equation}
R(\lambda) = \frac{I_{\text{sample}}(\lambda) - I_{\text{dark}}(\lambda)}{I_{\text{white}}(\lambda) - I_{\text{dark}}(\lambda)}
\end{equation}

โดย $I_{\text{sample}}(\lambda)$ คือความเข้มแสงสะท้อนจากตัวอย่างดิน, $I_{\text{white}}(\lambda)$ คือความเข้มแสงสะท้อนจากแผ่นเทียบสีขาว และ $I_{\text{dark}}(\lambda)$ คือค่าสัญญาณรบกวนเมื่อปิดไฟมืดสนิท (Dark Current Noise)

    มีช่องรับแสงเลนส์ขนาดเส้นผ่านศูนย์กลาง $20\text{ mm}$ พร้อมร่องใส่ปะเก็นยางโอริงหรือโฟม EVA ป้องกันแสงรั่วลอดเข้าสู่ตัวกล้อง
    
    \item \textbf{ลิ้นชักตลับใส่ดิน (Soil Sample Drawer - `npxai_soil_sample_drawer.stl`)}
    รางสไลด์พร้อมหลุมบรรจุดินขนาดเส้นผ่านศูนย์กลาง $35\text{ mm}$ ลึก $8\text{ mm}$ มีมือจับสลักนูนตัวอักษร ``NPxAI'' และช่องฝังแม่เหล็กนีโอไดเมียมขนาด $5 \times 2\text{ mm}$ เพื่อดูดยึดล็อกตำแหน่งถาดดินให้คงที่
    
    \item \textbf{ลูกสูบเกลี่ยหน้าดิน (Soil Leveler Press - `npxai_soil_leveler_press.stl`)}
    แป้นกดขนาดเส้นผ่านศูนย์กลาง $34\text{ mm}$ พร้อมก้านจับ สำหรับเกลี่ยและอัดผิวหน้าดินให้เรียบสนิท เพื่อลดเงาตกกระทบและความไม่สม่ำเสมอของพื้นผิว
\end{enumerate}

\section{ลำดับจังหวะการทำงานระหว่างสมาร์ทโฟนและกล่องมืด (Timing \& Control Flow)}

\begin{enumerate}
    \item ผู้ใช้งานกดปุ่ม ``สแกนดิน'' บนหน้าจอแอปพลิเคชัน
    \item แอปพลิเคชันทำการล็อกค่าพารามิเตอร์กล้องสมาร์ทโฟน (Lock Auto-Focus, ISO, และ White Balance) เพื่อป้องกันการปรับแสงอัตโนมัติ
    \item แอปพลิเคชันส่งสัญญาณ BLE Strobe Trigger ไปยังไมโครคอนโทรลเลอร์ ESP32 ภายในกล่อง
    \item ไมโครคอนโทรลเลอร์สั่งเปิดหลอด LED แถบคลื่นแรก (UV 405 nm) เป็นเวลา 250 มิลลิวินาที
    \item แอปพลิเคชันดึงภาพ Region of Interest (ROI) เฟรมที่ 1 กึ่งกลางหน้าจอ
    \item วนซ้ำขั้นตอนสโตรบแสงครบทั้ง 7 แถบความยาวคลื่นอย่างต่อเนื่องภายในเวลารวมประมาณ 2.5 วินาที
    \item รวบรวมเวกเตอร์สเปกตรัม Vis-NIR ผสานกับพิกัด GPS และประเภทแปลงเกษตรกรรม (Farming Type Prior)
    \item ส่งข้อมูลเข้าสู่โมเดลปัญญาประดิษฐ์บนขอบที่ผู้ใช้เลือก (MobileNetV4, Soil-ViT, หรือ ResNet18-DualBranch)
    \item แสดงผลค่า Total N และ Available P พร้อมคำแนะนำปุ๋ยเคมีสั่งตัดและชีวภัณฑ์บนหน้าจอทันที
\end{enumerate}

\section{การประมวลผลบนขอบแบบ Pure Dart Offline Inference}
แอปพลิเคชัน NPxAI ทำงานแบบออฟไลน์ $100\%$ โดยไม่มีการส่งภาพหรือข้อมูลขึ้นสู่เซิร์ฟเวอร์ภายนอก แบบจำลองปัญญาประดิษฐ์ทั้งหมดถูกสร้างขึ้นด้วยภาษา Pure Dart ทำงานผ่านเอนจินการคำนวณที่ปรับแต่งเฉพาะ (Edge Machine Learning Engine) ทำให้ใช้เวลาประมวลผลน้อยกว่า 50 มิลลิวินาทีต่อการสแกน

\section{การวิเคราะห์สาเหตุเชิงลึกและแก้ปัญหาผลการสแกนคงที่}
ในการทดสอบแอปพลิเคชันเวอร์ชันก่อนหน้า พบปัญหาสำคัญคือผลการทำนายธาตุอาหารแสดงค่าคงที่เดิมเสมอ แม้จะสลับเปลี่ยนโมเดลปัญญาประดิษฐ์แล้วก็ตาม ทีมวิจัยได้ทำการวิเคราะห์ซอร์สโค้ดและพบสาเหตุเชิงโครงสร้าง 3 ประการ

\begin{enumerate}
    \item \textbf{ค่าน้ำหนักคงที่ชุดเดียวในโมเดล} ในฟังก์ชัน \texttt{predictNutrients(...)} ของคลาส \texttt{EdgeAiInferenceUseCase} มีการกำหนดค่าน้ำหนักคงที่ (\texttt{\_weightsTotalN} และ \texttt{\_weightsAvailableP}) เพียงชุดเดียวสำหรับทุกแบบจำลอง
    \item \textbf{พารามิเตอร์โมเดลเป็นเพียงป้ายชื่อ (Passive Label)} ตัวแปร \texttt{modelName} ที่ส่งเข้ามา ทำหน้าที่เพียงแค่ป้ายกำกับสำหรับบันทึกประวัติการสแกน แต่ไม่ได้ถูกส่งเข้าสู่สมการการคำนวณหรือโครงข่ายประสาทเทียม
    \item \textbf{การขาดการเชื่อมโยงระบบการจัดการแปลง (Farming Type Prior)} ข้อมูลประเภทแปลงของเกษตรกร (อินทรีย์, เคมี, อินทรีย์เคมี) ยังไม่ได้ถูกเชื่อมต่อไปยังฟังก์ชันอนุมาน ทำให้ผลลัพธ์ได้ค่าคงที่ประมาณ $2.57\text{ g/kg}$ สำหรับ N และ $18.09\text{ mg/kg}$ สำหรับ P ตลอดเวลา
\end{enumerate}

ทีมวิจัยจึงได้ทำการรื้อโครงสร้างและพัฒนาระบบการอนุมานใหม่ โดยแยกสมการทางคณิตศาสตร์และจุดเด่นทางสเปกตรัมตามสถาปัตยกรรมของแต่ละโมเดลอย่างแท้จริง

\begin{enumerate}
    \item \textbf{SIMULATION (Baseline Standard)} โหมดจำลองเชิงสถิติอ้างอิงฐานข้อมูลสเปกตรัมดินมาตรฐาน ($R^2 \approx 0.91$, $N \approx 2.45 - 2.57\text{ g/kg}$, $P \approx 17.5 - 18.5\text{ mg/kg}$)
    
    \item \textbf{MobileNetV4-Soil (Inverted Bottleneck \& NDSI)} ออกแบบเพื่อตอบสนองต่อดัชนีผลต่างสเปกตรัมดิน Normalized Difference Soil Index ระหว่างย่าน $850\text{ nm}$ และ $630\text{ nm}$ ร่วมกับความเข้มสีดิน ($R^2 \approx 0.89 - 0.92$, $N \approx 2.68 - 2.82\text{ g/kg}$, $P \approx 21.5 - 24.0\text{ mg/kg}$)
    
    \item \textbf{EfficientNet-B0 (Compound Scaling \& Humus SOM)} ใช้การปรับขนาดผสมผสานเพื่อตรวจจับสารอินทรีย์ฮิวมัสในดินผ่านปริภูมิสี HSV (Saturation และ Value) เหมาะอย่างยิ่งสำหรับแปลงที่มีอินทรียวัตถุสูง ($R^2 \approx 0.93 - 0.94$, $N \approx 2.35 - 2.52\text{ g/kg}$, $P \approx 15.2 - 17.2\text{ mg/kg}$)
    
    \item \textbf{Soil-ViT (Vision Transformer Self-Attention)} โครงข่ายหม้อแปลงสายตาที่คำนวณการเอาใจใส่ตนเอง (Self-Attention) ระหว่างการสะท้อนย่าน $940\text{ nm}$ (Phosphate Lattice) และ $525\text{ nm}$ (Iron Oxides) ซึ่งเป็นย่านดูดกลืนแสงของฟอสฟอรัสโดยตรง ($R^2 \approx 0.95$, $N \approx 2.58 - 2.75\text{ g/kg}$, $P \approx 18.8 - 21.8\text{ mg/kg}$)
    
    \item \textbf{ResNet18-DualBranch (Multimodal Fusion)} โครงข่ายสองสาขาที่ผสานข้อมูลภาพสี RGB และเวกเตอร์สเปกตรัม Vis-NIR จากโฟโตไดโอด ให้ความแม่นยำสูงสุดในงานวิจัย ($R^2 \approx 0.96 - 0.97$, $N \approx 2.75 - 2.95\text{ g/kg}$, $P \approx 23.0 - 26.5\text{ mg/kg}$)
\end{enumerate}

\section{การวิเคราะห์สาเหตุเชิงลึกและแก้ปัญหาการแสดงผลตัวอักษรล้นจอ}
ในการทดสอบแอปพลิเคชันบนสมาร์ทโฟนจริง พบปัญหาข้อความบนการ์ดแสดงผลธาตุอาหารแสดงเพียง ``Total Nitrog...'' ในขณะที่ชื่อการ์ดฟอสฟอรัส ``Available P'' หายไปอย่างสิ้นเชิง จากการตรวจสอบโครงสร้างวิดเจ็ตในไฟล์ \texttt{nutrient\_gauge\_card.dart} พบสาเหตุดังนี้

\begin{enumerate}
    \item \textbf{การแบ่งพื้นที่จำกัดในแนวนอน} การ์ดแสดงผลธาตุอาหารทั้งสองการ์ดถูกจัดวางในวิดเจ็ต \texttt{Row} แบ่งครึ่งหน้าจอสมาร์ทโฟน ทำให้การ์ดแต่ละข้างมีความกว้างเพียงประมาณ 160 พิกเซล
    \item \textbf{การวางหัวข้อและป้ายระดับในบรรทัดเดียวกัน} ภายในการ์ดเดิม มีการนำชื่อหัวข้อ (\texttt{title}) และป้ายระดับธาตุอาหาร (\texttt{level.labelTh}) มาวางต่อกันในแนวนอน
    \item \textbf{การชนกันของข้อความและการตัดทอน (Ellipsis Truncation)} ในการ์ดฝั่งขวา (ฟอสฟอรัส) ข้อความระดับคือ ``ปานกลาง (เหมาะสม)'' มีความยาวถึง 17 ตัวอักษร กินพื้นที่ไปเกือบ 110 พิกเซล ส่งผลให้พื้นที่สำหรับข้อความ ``Available P (Bray II)'' เหลือไม่ถึง 25 พิกเซล เมื่อถูกครอบด้วยวิดเจ็ต \texttt{Expanded} ร่วมกับ \texttt{TextOverflow.ellipsis} ข้อความจึงถูกตัดทอนจนหายไปทั้งประโยค ส่วนการ์ดฝั่งซ้าย (ไนโตรเจน) ป้ายระดับคือ ``สูงมาก'' สั้นกว่า จึงเหลือพื้นที่บางส่วนแต่ก็ยังถูกตัดคำกลายเป็น ``Total Nitrog...''
\end{enumerate}

ทีมวิจัยได้ทำการปรับปรุงโครงสร้างภายในของ \texttt{NutrientGaugeCard} ใหม่ทั้งหมด โดยแยกออกเป็น 2 ชั้นอย่างอิสระ

\begin{itemize}
    \item \textbf{แถวบน (Header Row)} แสดงสัญลักษณ์ธาตุเคมีเด่นชัดคู่กับชื่อย่อ เช่น \texttt{[N] Total N} และ \texttt{[P] Available P} วางคู่กับป้ายระดับธาตุอาหาร ช่วยประหยัดพื้นที่แนวนอน
    \item \textbf{แถวคำอธิบายกำกับมาตรฐาน (Standard Subtitle Row)} เพิ่มบรรทัดแยกด้านล่างสำหรับระบุวิธีวิเคราะห์ตามมาตรฐานปฐพีวิทยาสากล ได้แก่ \texttt{ไนโตรเจนทั้งหมด (Kjeldahl)} ใต้การ์ด N และ \texttt{ฟอสฟอรัสที่เป็นประโยชน์ (Bray II)} ใต้การ์ด P
\end{itemize}

การปรับปรุงนี้ช่วยป้องกันการชนกันของข้อความได้ $100\%$ ทำให้ชื่อธาตุอาหารและระดับแสดงผลได้คมชัด สมบูรณ์ในทุกขนาดหน้าจอสมาร์ทโฟน

\begin{itemize}
    \item \textbf{ระบบพิกัด GPS อัตโนมัติ} แสดงผลพิกัดละติจูดและลองจิจูดในบรรทัดเดียวกัน พร้อมระบุทิศทางภูมิศาสตร์สากล (N/S/E/W) เช่น \texttt{12.613725° N | 102.103862° E}
    \item \textbf{ชุดปุ่มควบคุมการบันทึก 3 รูปแบบ} จัดวางปุ่มคำสั่งสำคัญไว้กึ่งกลางหน้าจออย่างชัดเจน ประกอบด้วย ปุ่มสแกนวิเคราะห์ดิน (Scan), ปุ่มบันทึกภาพถ่าย (Photo Capture) สำหรับจัดเก็บคลังข้อมูลภาพดิน และปุ่มบันทึกวิดีโอ (Video Record)
    \item \textbf{ป้ายกำกับโมเดลแบบไดนามิก (Dynamic Model Selector Badge)} แสดงชื่อโมเดลที่กำลังทำงานอย่างชัดเจนในการ์ดข้อมูลตัวอย่างดินด้านบน และปรับเปลี่ยนผลการทำนายทันทีเมื่อผู้ใช้งานสลับโมเดล
\end{itemize}

\begin{dartcode}[เอนจินการคำนวณแบบจำลองปัญญาประดิษฐ์หลากสถาปัตยกรรม (Pure Dart)]
class MultiModelEdgePredictor {
  // Multi-Model Edge Inference Switching
  NutrientPrediction predict({
    required SpectralSignature signature,
    required AiModelType modelType,
  }) {
    switch (modelType) {
      case AiModelType.cnnResNet:
        return _predictCnnResNet(signature);
      case AiModelType.randomForest:
        return _predictRandomForest(signature);
      case AiModelType.annPerceptron:
        return _predictAnnPerceptron(signature);
      case AiModelType.svrRbf:
        return _predictSvrRbf(signature);
      case AiModelType.plsrChemometrics:
        return _predictPlsr(signature);
    }
  }

  NutrientPrediction _predictAnnPerceptron(SpectralSignature sig) {
    final List<double> x = sig.toFeatureVector();
    double nSum = -0.42;
    for (int i = 0; i < x.length; i++) nSum += x[i] * _annWeightsN[i];
    final double predN = 0.45 + (2.65 / (1.0 + exp(-nSum * 0.82)));

    double pSum = 3.8;
    for (int i = 0; i < x.length; i++) pSum += x[i] * _annWeightsP[i];
    final double predP = max(2.5, pSum);

    return NutrientPrediction(
      totalNitrogen: predN,
      availablePhosphorus: predP,
      confidenceScore: 0.945,
    );
  }
}
\end{dartcode}
