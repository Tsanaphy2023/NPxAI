\chapter{ความเป็นมาและรากฐานทางทฤษฎี}

\section{ความเป็นมาและความสำคัญของปัญหา}
ดินในพื้นที่เกษตรกรรมของจังหวัดจันทบุรีและตราด โดยเฉพาะสวนทุเรียน มังคุด และเงาะ ประสบปัญหาการสะสมของธาตุอาหารไม่สมดุลจากการใช้ปุ๋ยเคมีในปริมาณสูงติดต่อกันเป็นเวลานาน การส่งตัวอย่างดินไปตรวจวิเคราะห์ในห้องปฏิบัติการมาตรฐานใช้เวลานาน 7 ถึง 14 วัน และมีค่าใช้จ่ายสูง ทำให้เกษตรกรขาดข้อมูลประกอบการตัดสินใจแบบทันท่วงที ส่งผลให้เกิดการสะสมของฟอสฟอรัสตกค้างที่ไม่เป็นประโยชน์ และเกิดการชะล้างไนโตรเจนลงสู่แหล่งน้ำธรรมชาติ

งานวิจัยนี้จึงมุ่งพัฒนานวัตกรรมเครื่องมือวิเคราะห์ดินแบบพกพาโดยใช้เทคนิค Visible and Near-Infrared Diffuse Reflectance Spectroscopy ร่วมกับปัญญาประดิษฐ์บนอุปกรณ์เคลื่อนที่ เพื่อให้เกษตรกรทราบปริมาณไนโตรเจนทั้งหมด (Total Nitrogen) และฟอสฟอรัสที่เป็นประโยชน์ (Available Phosphorus) ในแปลงปลูกได้ทันทีภายใน 3 วินาที พร้อมเชื่อมโยงคำแนะนำชีวภัณฑ์จุลินทรีย์ดินท้องถิ่น

\section{ทฤษฎีการสะท้อนแสงแบบกระจายและพันธะโมเลกุลในดิน}
เมื่อลำแสงตกกระทบลงบนผิวหน้าของอนุภาคดิน แสงจะเกิดการสะท้อนสองลักษณะ ได้แก่ การสะท้อนแบบสเปคิวลาร์ (Specular Reflection) ที่สะท้อนตามกฎการสะท้อนเชิงเรขาคณิต และการสะท้อนแบบกระจาย (Diffuse Reflectance) ที่แทรกซึมเข้าไปในเนื้อดินแล้วสะท้อนกลับออกมาหลังจากเกิดปฏิสัมพันธ์กับการดูดกลืนแสงของโมเลกุล

\centering

ปริมาณการดูดกลืนแสงและค่าความสะท้อนสัมพันธ์ ($R_\lambda$) เป็นไปตามทฤษฎีคูเบลกา-มองค์ (Kubelka-Munk Theory) ดังสมการ

\begin{equation}
F(R_\infty) = \frac{(1 - R_\infty)^2}{2 R_\infty} = \frac{K}{S}
\end{equation}

โดย $K$ คือสัมประสิทธิ์การดูดกลืนแสง (Absorption Coefficient) และ $S$ คือสัมประสิทธิ์การกระเจิงแสง (Scattering Coefficient) ซึ่งแปรผันตามขนาดของอนุภาคดินและความชื้น

\section{การไขความกระจ่างทางวิทยาศาสตร์ ความสัมพันธ์ระหว่าง Total N และ Available P}
ในการพัฒนาแบบจำลองระยะแรก มักพบข้อสงสัยว่าเหตุใดจึงตรวจวัดค่าไนโตรเจนทั้งหมด (Total N) ได้อย่างรวดเร็ว ในขณะที่ฟอสฟอรัสที่เป็นประโยชน์ (Available P) มีความซับซ้อนและตรวจจับได้ยากกว่ามาก ข้อเท็จจริงทางฟิสิกส์สเปกโทรสโกปีอธิบายได้ดังนี้

\begin{enumerate}
    \item \textbf{ไนโตรเจนทั้งหมด (Total N)} ไนโตรเจนมากกว่า 90\% ในดินเกษตรกรรมผูกพันอยู่กับอินทรียวัตถุในดิน (Soil Organic Matter หรือ SOM) ซึ่งประกอบด้วยพันธะ C-H, N-H และ O-H อินทรียวัตถุนี้ส่งผลโดยตรงต่อค่าความมืดสว่าง (Value / Brightness) และความเข้มสีของดินอย่างชัดเจนในย่านแสงที่ตามองเห็น ($400 - 700\text{ nm}$) และย่านอินฟราเรดย่านใกล้ $850\text{ nm}$ จึงทำให้ระบบสามารถประเมินค่าทางอ้อม (Colorimetric Proxy) ได้อย่างแม่นยำแม้ใช้เพียงเซนเซอร์ RGB
    
    \item \textbf{ฟอสฟอรัสที่เป็นประโยชน์ (Available P)} ฟอสฟอรัสในดินไม่ได้เป็นเม็ดสีที่ให้ค่าสีจำเพาะต่อสายตามนุษย์ แต่มักอยู่ในรูปของสารประกอบออร์โธฟอสเฟตที่จับตัวอยู่กับสารประกอบเหล็กออกไซด์ (Iron Oxides) และอะลูมิเนียมในดินกรด การตรวจวัดฟอสฟอรัสจึงต้องการการดูดกลืนแสงในช่วงคลื่นจำเพาะ ได้แก่ $525\text{ nm}$ และย่านอินฟราเรดย่านใกล้ $940\text{ nm}$ ซึ่งเกินขอบเขตที่แสงขาวธรรมดาจะให้ข้อมูลได้โดยตรง
\end{enumerate}

\chapter{ฟิสิกส์เชิงแสงและสถาปัตยกรรมฮาร์ดแวร์}

\section{การควบคุมแสงรบกวน 0-Lux และเรขาคณิตเชิงแสง CIE 45°/0°}
การตรวจวัดการสะท้อนแสงในแปลงเกษตรกรรมจำเป็นต้องควบคุมสภาพแวดล้อมให้มืดสนิท (0-Lux Ambient Light) เพื่อป้องกันแสงแดดและแสงหลอดไฟภายนอกรบกวน กล่องมืด (Dark Chamber) จึงถูกออกแบบตามมาตรฐานสากล CIE 45°/0° โดยจัดตำแหน่งแหล่งกำเนิดแสงทำมุม 45 องศากับแนวตั้งฉากของผิวหน้าดิน และติดตั้งกล้องสมาร์ทโฟนไว้ที่แนวตั้งฉาก 0 องศา (Nadir Angle) การจัดมุมนี้ทำให้แสงสะท้อนผิวหน้าแบบกระจก (Specular Reflection หรือ Direct Glare) สะท้อนออกไปในทิศทาง 45 องศาฝั่งตรงข้าม ไม่เข้าสู่หน้าเลนส์กล้อง ทำให้เซนเซอร์กล้องรับเฉพาะแสงสะท้อนแบบกระเจิง (Diffuse Reflectance) ซึ่งเป็นแสงที่ทำอันตรกิริยากับพันธะเคมี สารอินทรีย์ และเม็ดสีของเนื้อดินจริง

\subsection{วงจรขับกระแสและการควบคุมสโตรบป้องกันแถบคลื่นดำ}
วงจรขับหลอด LED ใช้ไอซีขับกระแสคงที่ประเภท Buck LED Driver (เช่น AL8860 หรือ PT4115) เพื่อควบคุมความเข้มแสงให้คงที่สม่ำเสมอแม้แรงดันแบตเตอรี่จะลดลงระหว่างใช้งานภาคสนาม นอกจากนี้ เซนเซอร์ CMOS ของสมาร์ทโฟนใช้ชัตเตอร์แบบกลิ้ง (Rolling Shutter) หากควบคุมแสงด้วยสัญญาณ PWM ความถี่ต่ำ ภาพที่ได้จะเกิดแถบคลื่นมืดสลับสว่าง (Rolling Shutter Banding) ระบบจึงควบคุมการเปิด-ปิดแสงด้วยสัญญาณสโตรบกระแสตรงต่อเนื่อง (DC Continuous Pulse) ในช่วงจังหวะการบันทึกภาพ (200 ถึง 300 มิลลิวินาทีต่อแชนเนล) หรือใช้ความถี่ PWM สูงกว่า 25 kHz ขึ้นไป

\section{การวิเคราะห์เชิงเปรียบเทียบแหล่งกำเนิดแสงและการประยุกต์ใช้แฟลชสมาร์ทโฟน}
โครงการวิจัยได้ทำการศึกษาวิจัยเชิงลึกถึงความเป็นไปได้ในการใช้ไฟฉายแฟลชในสมาร์ทโฟนเป็นแหล่งกำเนิดแสง พบว่าสามารถใช้งานได้จริงในระบบพกพาต้นทุนต่ำ (NPxAI Lite) โดยมีข้อดีคือกล่องมืดไม่ต้องมีวงจรไฟฟ้าหรือแบตเตอรี่ เกษตรกรสามารถนำสมาร์ทโฟนมาประกบและสแกนได้ทันทีผ่านคำสั่งเปิดไฟฉาย (Torch Mode) ของแอปพลิเคชัน

อย่างไรก็ดี หลอดแฟลชสมาร์ทโฟนเป็นหลอด Blue LED เคลือบสารฟอสเฟอร์สีเหลือง ครอบคลุมเฉพาะแสงที่ตามองเห็น ($450 - 650\text{ nm}$) ปราศจากคลื่นย่าน NIR อีกทั้งตำแหน่งหลอดแฟลชอยู่ชิดเลนส์กล้องมาก ($5 - 12\text{ mm}$) หากส่องตรงลงไปจะเกิดแสงสะท้อนจ้า (Specular Glare) เข้าสู่เลนส์ ทีมวิจัยจึงได้ออกแบบแนวทางแก้ไขเชิงวิศวกรรมดังนี้

\begin{enumerate}
    \item \textbf{ท่อนำแสงเอียงและแผ่นกระจายแสง (Optical Light Pipe \& 45° Deflector)}
    ภายในกล่องทำท่อนำแสงเอียงรับแสงจากหลอดแฟลชแล้วหักเหให้ตกกระทบหน้าดินที่มุม 45 องศา พร้อมติดตั้งแผ่นอะคริลิกฝ้าหนา 1 mm (Diffuser) หน้าช่องแสงเพื่อเกลี่ยแสงให้เป็นลัมเบอร์เชียน (Lambertian Illumination) กระจายตัวสม่ำเสมอทั่วหน้าดิน ไร้จุดสว่างจ้า
    
    \item \textbf{การสอบเทียบแสงแบบเวลาจริงด้วยแผ่นเทียบสีขาว (Real-Time White Tile Normalization)}
    ติดตั้งแผ่นเทียบสีขาวมาตรฐาน (PTFE Tile 99\% Reflectance) ขนาด $10 \times 10\text{ mm}$ ไว้ที่ขอบภาพ เพื่อให้ระบบคำนวณชดเชยการลดทอนของแสงแฟลชจากความร้อน (Thermal Dimming) ได้แบบไดนามิก
    
    \item \textbf{การประมาณค่าด้วย Colorimetric Proxy}
    โครงข่ายประสาทเทียมจะประมาณค่าไนโตรเจนและฟอสฟอรัสทางอ้อมผ่านความเข้มข้นของอินทรียวัตถุในดิน (SOM), ความชื้น, และระบบสีดิน Munsell (Hue, Value, Chroma) ให้ความแม่นยำ $R^2 \approx 0.78 - 0.85$ ซึ่งเพียงพอสำหรับการแนะนำการใส่ปุ๋ยเบื้องต้น
\end{enumerate}

\subsection{ข้อกำหนดทางฟิสิกส์ว่าด้วยการเปิดแฟลชสมาร์ทโฟนในโหมด NPxAI Lite}
คำถามเชิงวิศวกรรมที่สำคัญในการปฏิบัติงานคือ: \textbf{``เมื่อเลือกโหมด NPxAI Lite จำเป็นต้องเปิดไฟแฟลชของสมาร์ทโฟนหรือไม่?''}

คำตอบเชิงวิทยาศาสตร์คือ \textbf{``จำเป็นต้องเปิดไฟแฟลชเสมอ ($100\%$ Mandatory)''} เนื่องจากเหตุผลเชิงฟิสิกส์และสถาปัตยกรรมเชิงแสงดังต่อไปนี้
\begin{enumerate}
    \item \textbf{สภาวะกล่องมืดสัมบูรณ์ (Zero-Lux Dark Chamber)}
    โครงสร้างกล่อง NPxAI Lite ถูกพิมพ์ขึ้นรูปด้วยพลาสติก PLA ทึบแสงสีดำเพื่อป้องกันแสงรบกวนภายนอก (Ambient Light Rejection) หากไม่เปิดแฟลช ภายในห้องตรวจวัดจะมีความเข้มแสง $0\text{ Lux}$ ส่งผลให้เซนเซอร์รับภาพ CMOS ของสมาร์ทโฟนไม่ได้รับโฟตอนใดๆ และไม่สามารถบันทึกสัญญาณภาพตัวอย่างดินได้
    
    \item \textbf{การจับคู่ลำแสงผ่านท่อนำแสง 45 องศา (45° Light Guide Optical Coupling)}
    โครงสร้างกล่อง Lite ไม่มีแหล่งกำเนิดแสงหรือวงจรไฟฟ้าใดๆ ภายในตัว แต่ใช้ท่อนำแสงเอียง $45^\circ$ (Optical Light Pipe) ที่ทำหน้าที่เป็นท่อนำคลื่นโฟตอน ดึงแสงจากหลอดไฟฉายแฟลชของโทรศัพท์ ยิงตกกระทบหน้าตัวอย่างดินในมุม $45^\circ$ และให้เลนส์กล้องรับแสงสะท้อนที่มุมตั้งฉาก $0^\circ$ ตามมาตรฐานสากล CIE $45^\circ/0^\circ$ อย่างเคร่งครัด
    
    \item \textbf{ระบบเปิดแฟลชอัตโนมัติ (Auto-Torch Control)}
    เพื่ออำนวยความสะดวกแก่ผู้ใช้งานและป้องกันข้อผิดพลาดจากมนุษย์ แอปพลิเคชัน NPxAI ได้เขียนโปรแกรมควบคุมระดับฮาร์ดแวร์ เมื่ออยู่ในโหมด NPxAI Lite ระบบจะสั่งเปิดหลอดแฟลชในโหมดไฟฉายฉายต่อเนื่อง (Continuous Torch Mode) ส่องผ่านท่อนำแสง $45^\circ$ ลงสู่หน้าดินโดยอัตโนมัติในทุกคำสั่งตรวจวัด ได้แก่:
    \begin{itemize}
        \item \textbf{เมื่อกดปุ่มสแกนดิน (Scan):} เปิดไฟฉายแฟลชอัตโนมัติ หน่วงเวลา $200\text{ ms}$ ให้ความสว่างคงที่ แล้วสแกนคำนวณ N-P-K-OM ก่อนปิดแฟลชอัตโนมัติ
        \item \textbf{เมื่อกดปุ่มถ่ายภาพ (Photo Capture):} เปิดไฟฉายแฟลชอัตโนมัติ หน่วงเวลา $250\text{ ms}$ บันทึกภาพความละเอียดสูง แล้วปิดแฟลชอัตโนมัติ
        \item \textbf{เมื่อกดปุ่มสตรีมวิดีโอ (Live Video Stream):} เปิดไฟฉายแฟลชต่อเนื่องตลอดช่วงการวิเคราะห์แบบเรียลไทม์ และปิดไฟทันทีเมื่อหยุดสตรีม
    \end{itemize}
\end{enumerate}

\subsection{สถาปัตยกรรมการเชื่อมต่อและควบคุมในโหมด NPxAI Pro}
ในโหมดความแม่นยำสูงระดับห้องปฏิบัติการ (NPxAI Pro) การควบคุมการฉายแสงของหลอด LED มัลติสเปกตรัลทั้ง 7 แถบคลื่น และการรับส่งข้อมูลการตรวจวัด ได้รับการออกแบบภายใต้สถาปัตยกรรม \textbf{การเชื่อมต่อคู่ขนานสองระบบ (Dual-Interface Hybrid Connectivity)} ซึ่งรองรับทั้งการเชื่อมต่อไร้สายและแบบมีสาย ดังนี้

\begin{enumerate}
    \item \textbf{ระบบไร้สาย Bluetooth Low Energy 5.0 (BLE Mode) --- แนะนำสำหรับงานภาคสนาม}
    \begin{itemize}
        \item \textbf{ลักษณะการทำงาน:} ไมโครคอนโทรลเลอร์ที่ติดตั้งในกล่องมืด (ESP32-S3) จะกระจายสัญญาณ BLE GATT Service เพื่อให้สมาร์ทโฟนจับคู่ไร้สายอัตโนมัติ
        \item \textbf{โปรโตคอลการสั่งการ:} แอปพลิเคชันจะส่งคำสั่งสโตรบ (Strobe Pulse Command) ผ่าน Custom Characteristic ไปยังวงจรขับกระแส เพื่อสั่งเปิด-ปิดหลอด LED 7 ความยาวคลื่นทีละคู่เรียงตามลำดับเวลา (Time-Division Multiplexing) ให้สอดคล้องกับชัตเตอร์กล้อง
        \item \textbf{ข้อดี:} สะดวก คล่องตัว ไม่มีสายระโยงระยางขณะเดินสำรวจในแปลงเกษตรกรรม พร้อมส่งค่าโทรมาตร (Battery Level, Chamber Temperature, Humidity) กลับสู่หน้าจอแอปพลิเคชัน
    \end{itemize}

    \item \textbf{ระบบเชื่อมต่อผ่านสาย USB-C OTG Serial CDC (Wired Mode) --- แนะนำสำหรับห้องปฏิบัติการ}
    \begin{itemize}
        \item \textbf{ลักษณะการทำงาน:} ใช้สายเคเบิล USB-C แบบสองทิศทาง (Type-C to Type-C) เชื่อมระหว่างสมาร์ทโฟนและบอร์ดไมโครคอนโทรลเลอร์ โดยระบบจะจำลองพอร์ตเป็น USB Communication Device Class (CDC Virtual COM Port) อัตราความเร็วรับส่ง $115,200\text{ bps}$
        \item \textbf{ข้อดี:} อัตราความหน่วงต่ำระดับศูนย์ (Zero Latency), ความน่าเชื่อถือของสัญญาณสูง $100\%$ ปราศจากสัญญาณคลื่นวิทยุรบกวนในห้องแล็บ และสามารถจ่ายกระแสไฟฟ้า (USB Bus-Powered 5V/1A) จากสมาร์ทโฟนหรือคอมพิวเตอร์ไปเลี้ยงวงจรขับหลอด LED มัลติสเปกตรัลได้โดยตรงโดยไม่ต้องอาศัยแบตเตอรี่ภายในกล่อง
    \end{itemize}
\end{enumerate}

\section{แหล่งรับแสงและการปรับเทียบสีมาตรฐาน (Light Detector \& Calibration)}
แหล่งรับแสงของระบบแบ่งออกเป็น 2 ระดับ ได้แก่

\begin{enumerate}
    \item \textbf{แหล่งรับแสงหลัก (Primary Detector)} ใช้เซนเซอร์รับภาพ CMOS ในกล้องหลักของสมาร์ทโฟน (Main Wide Camera) มีฟิลเตอร์สีแบบไบเยอร์ (Bayer Color Filter Array) ทำหน้าที่รับแสงสะท้อนแบบกระจายและแปลงเป็นสัญญาณดิจิทัล โดยแอปพลิเคชัน NPxAI จะดึงภาพจากพิกัดพื้นที่สนใจ (Region of Interest: ROI) ขนาด $120 \times 120\text{ pixels}$ กึ่งกลางช่องมองภาพ มาคำนวณการดูดกลืนแสงและปริภูมิสี
    
    \item \textbf{แหล่งรับแสงเสริม (Auxiliary NIR Photodetector)} เนื่องจากเลนส์กล้องสมาร์ทโฟนทั่วไปมีแผ่นกรองแสงอินฟราเรด (IR Cut-off Filter) ติดตั้งอยู่หน้าเซนเซอร์ ทำให้ความไวแสงลดลงที่ความยาวคลื่นเกิน $750\text{ nm}$ ในรุ่น NPxAI Pro จึงสามารถติดตั้งเซนเซอร์สเปกตรัม Vis-NIR ขนาดจิ๋ว (เช่น AS7263 หรือ OPT101 Silicon Photodiode) เสริมไว้ข้างเลนส์กล้อง เพื่อตรวจรับคลื่น $850\text{ nm}$ และ $940\text{ nm}$ ได้โดยตรง
\end{enumerate}

ค่าการสะท้อนแสงสัมพัทธ์ของดินคำนวณเทียบกับแผ่นเทียบสีขาวมาตรฐาน ($\text{BaSO}_4$ หรือ PTFE $99\%$) ดังสมการ

\begin{equation}
R(\lambda) = \frac{I_{\text{sample}}(\lambda) - I_{\text{dark}}(\lambda)}{I_{\text{white}}(\lambda) - I_{\text{dark}}(\lambda)}
\end{equation}

โดย $I_{\text{sample}}(\lambda)$ คือความเข้มแสงสะท้อนจากตัวอย่างดิน, $I_{\text{white}}(\lambda)$ คือความเข้มแสงสะท้อนจากแผ่นเทียบสีขาว และ $I_{\text{dark}}(\lambda)$ คือค่าสัญญาณรบกวนเมื่อปิดไฟมืดสนิท (Dark Current Noise)

\section{การประมวลผลบนขอบแบบ Pure Dart Offline Inference}
แอปพลิเคชัน NPxAI ทำงานแบบออฟไลน์ $100\%$ โดยไม่มีการส่งภาพหรือข้อมูลขึ้นสู่เซิร์ฟเวอร์ภายนอก แบบจำลองปัญญาประดิษฐ์ทั้งหมดถูกสร้างขึ้นด้วยภาษา Pure Dart ทำงานผ่านเอนจินการคำนวณที่ปรับแต่งเฉพาะ (Edge Machine Learning Engine) ทำให้ใช้เวลาประมวลผลน้อยกว่า 50 มิลลิวินาทีต่อการสแกน

\section{การวิเคราะห์สาเหตุเชิงลึกและแก้ปัญหาผลการสแกนคงที่}
ในการทดสอบแอปพลิเคชันเวอร์ชันก่อนหน้า พบปัญหาสำคัญคือผลการทำนายธาตุอาหารแสดงค่าคงที่เดิมเสมอ แม้จะสลับเปลี่ยนโมเดลปัญญาประดิษฐ์แล้วก็ตาม ทีมวิจัยได้ทำการวิเคราะห์ซอร์สโค้ดและพบสาเหตุเชิงโครงสร้าง 3 ประการ

\begin{enumerate}
    \item \textbf{ค่าน้ำหนักคงที่ชุดเดียวในโมเดล} ในฟังก์ชัน \texttt{predictNutrients(...)} ของคลาส \texttt{EdgeAiInferenceUseCase} มีการกำหนดค่าน้ำหนักคงที่ (\texttt{\_weightsTotalN} และ \texttt{\_weightsAvailableP}) เพียงชุดเดียวสำหรับทุกแบบจำลอง
    \item \textbf{พารามิเตอร์โมเดลเป็นเพียงป้ายชื่อ (Passive Label)} ตัวแปร \texttt{modelName} ที่ส่งเข้ามา ทำหน้าที่เพียงแค่ป้ายกำกับสำหรับบันทึกประวัติการสแกน แต่ไม่ได้ถูกส่งเข้าสู่สมการการคำนวณหรือโครงข่ายประสาทเทียม
    \item \textbf{การขาดการเชื่อมโยงระบบการจัดการแปลง (Farming Type Prior)} ข้อมูลประเภทแปลงของเกษตรกร (อินทรีย์, เคมี, อินทรีย์เคมี) ยังไม่ได้ถูกเชื่อมต่อไปยังฟังก์ชันอนุมาน ทำให้ผลลัพธ์ได้ค่าคงที่ประมาณ $2.57\text{ g/kg}$ สำหรับ N และ $18.09\text{ mg/kg}$ สำหรับ P ตลอดเวลา
\end{enumerate}

ทีมวิจัยจึงได้ทำการรื้อโครงสร้างและพัฒนาระบบการอนุมานใหม่ โดยแยกสมการทางคณิตศาสตร์และจุดเด่นทางสเปกตรัมตามสถาปัตยกรรมของแต่ละโมเดลอย่างแท้จริง

\begin{enumerate}
    \item \textbf{SIMULATION (Baseline Standard)} โหมดจำลองเชิงสถิติอ้างอิงฐานข้อมูลสเปกตรัมดินมาตรฐาน ($R^2 \approx 0.91$, $N \approx 2.45 - 2.57\text{ g/kg}$, $P \approx 17.5 - 18.5\text{ mg/kg}$)
    
    \item \textbf{MobileNetV4-Soil (Inverted Bottleneck \& NDSI)} ออกแบบเพื่อตอบสนองต่อดัชนีผลต่างสเปกตรัมดิน Normalized Difference Soil Index ระหว่างย่าน $850\text{ nm}$ และ $630\text{ nm}$ ร่วมกับความเข้มสีดิน ($R^2 \approx 0.89 - 0.92$, $N \approx 2.68 - 2.82\text{ g/kg}$, $P \approx 21.5 - 24.0\text{ mg/kg}$)
    
    \item \textbf{EfficientNet-B0 (Compound Scaling \& Humus SOM)} ใช้การปรับขนาดผสมผสานเพื่อตรวจจับสารอินทรีย์ฮิวมัสในดินผ่านปริภูมิสี HSV (Saturation และ Value) เหมาะอย่างยิ่งสำหรับแปลงที่มีอินทรียวัตถุสูง ($R^2 \approx 0.93 - 0.94$, $N \approx 2.35 - 2.52\text{ g/kg}$, $P \approx 15.2 - 17.2\text{ mg/kg}$)
    
    \item \textbf{Soil-ViT (Vision Transformer Self-Attention)} โครงข่ายหม้อแปลงสายตาที่คำนวณการเอาใจใส่ตนเอง (Self-Attention) ระหว่างการสะท้อนย่าน $940\text{ nm}$ (Phosphate Lattice) และ $525\text{ nm}$ (Iron Oxides) ซึ่งเป็นย่านดูดกลืนแสงของฟอสฟอรัสโดยตรง ($R^2 \approx 0.95$, $N \approx 2.58 - 2.75\text{ g/kg}$, $P \approx 18.8 - 21.8\text{ mg/kg}$)
    
    \item \textbf{ResNet18-DualBranch (Multimodal Fusion)} โครงข่ายสองสาขาที่ผสานข้อมูลภาพสี RGB และเวกเตอร์สเปกตรัม Vis-NIR จากโฟโตไดโอด ให้ความแม่นยำสูงสุดในงานวิจัย ($R^2 \approx 0.96 - 0.97$, $N \approx 2.75 - 2.95\text{ g/kg}$, $P \approx 23.0 - 26.5\text{ mg/kg}$)
\end{enumerate}

นอกจากนี้ ระบบยังได้เชื่อมโยงสมมติฐานการจัดการแปลง (Farming Type Prior) เข้าสู่สมการการอนุมาน ได้แก่ แปลงอินทรีย์จะปรับเพิ่ม Total N ($+0.35\text{ g/kg}$) ตามปริมาณปุ๋ยหมักและอินทรียวัตถุ, แปลงเคมีจะปรับเพิ่ม Available P ($+7.5\text{ mg/kg}$) ตามการตกค้างของปุ๋ยฟอสเฟต และแปลงอินทรีย์เคมีจะปรับเข้าสู่เกณฑ์สมดุล

\chapter{สถาปัตยกรรมแอปพลิเคชันและการจัดการดินแม่นยำ}

\section{การออกแบบสถาปัตยกรรมแสดงผล 4 พารามิเตอร์ดิน (N-P-K และ SOM/OM) และเลย์เอาต์ Symmetric 2x2 Grid}
ในการวิเคราะห์ดินตามหลักปฐพีวิทยา นอกจากธาตุอาหารหลัก 3 ชนิด ได้แก่ ไนโตรเจน (N), ฟอสฟอรัส (P) และโพแทสเซียม (K) แล้ว \textbf{อินทรียวัตถุในดิน (Soil Organic Matter: SOM หรือ OM)} ถือเป็นตัวชี้วัดความอุดมสมบูรณ์ที่สำคัญที่สุด เนื่องจากเป็นแหล่งกักเก็บธาตุอาหารหลัก ช่วยเพิ่มความจุในการแลกเปลี่ยนประจุบวก (Cation Exchange Capacity: CEC) และรักษาความชื้นในดิน

โครงการวิจัย NPxAI จึงได้ขยายการวิเคราะห์ครอบคลุมครบ 4 พารามิเตอร์เคมีดิน พร้อมพัฒนาสถาปัตยกรรมการแสดงผลแบบตารางสมมาตร (Symmetric 2x2 Grid Layout) ในไฟล์ \texttt{analysis\_result\_view.dart} และ \texttt{nutrient\_gauge\_card.dart} ดังนี้

\begin{enumerate}
    \item \textbf{การจัดวางเลย์เอาต์แบบ Symmetric 2x2 Grid}
    \begin{itemize}
        \item จัดแบ่งการ์ดแสดงผลออกเป็น 2 แถว แถวละ 2 คอลัมน์อย่างสมดุล ($50\% - 50\%$)
        \item \textbf{แถวบน:} การ์ด Total Nitrogen (g/kg, Kjeldahl) และ Available Phosphorus (mg/kg, Bray II)
        \item \textbf{แถวล่าง:} การ์ด Available Potassium (mg/kg, 1N NH4OAc) และ Soil Organic Matter (\%, Walkley-Black)
        \item ทุกการ์ดได้รับพื้นที่เท่ากัน มีความสมมาตรทางสายตา ไร้ปัญหาข้อความล้นจอ ($0\%\text{ Overflow}$) บนสมาร์ทโฟนทุกขนาด
    \end{itemize}

    \item \textbf{เกณฑ์การจำแนกระดับอินทรียวัตถุในดิน (OM Classification)}
    อ้างอิงตามเกณฑ์มาตรฐานกรมพัฒนาที่ดิน (Land Development Department: DLD) แบ่งออกเป็น 5 ระดับ ได้แก่
    \begin{itemize}
        \item \textbf{ต่ำมาก ($< 1.0\%$):} ดินทรายหรือดินเสื่อมโทรมรุนแรง ต้องเติมปุ๋ยหมัก/ปุ๋ยคอกปริมาณมาก
        \item \textbf{ต่ำ ($1.0 - 1.5\%$):} ดินมีฮิวมัสน้อย ต้องการการปรับปรุงดินด้วยอินทรียวัตถุ
        \item \textbf{ปานกลาง ($1.5 - 2.5\%$):} ระดับมาตรฐานสำหรับดินปลูกไม้ผลในภาคตะวันออก
        \item \textbf{สูง ($2.5 - 3.5\%$):} ดินมีความอุดมสมบูรณ์ดี โครงสร้างดินโปร่งร่วนซุย
        \item \textbf{สูงมาก ($> 3.5\%$):} ดินอินทรีย์หรือดินที่มีการจัดการชีวภาพอย่างต่อเนื่อง
    \end{itemize}

    \item \textbf{ระบบชุดสีมาตรฐานและการเปลี่ยนเฉดสีตามระดับการวิเคราะห์ (Nutrient Color Palette \& 5-Level Rating Shades)}
    เพื่อยกระดับการตีความผลการวิเคราะห์ให้เกษตรกรและนักวิชาการสามารถวินิจฉัยสุขภาพดินได้อย่างรวดเร็วและถูกต้อง แอปพลิเคชัน NPxAI ได้นำระบบสีคู่ขนานสองมิติ (Dual-Dimension Color Architecture) มาประยุกต์ใช้ในโมดูล \texttt{nutrient\_color\_palette.dart} ดังนี้
    \begin{itemize}
        \item \textbf{มิติที่ 1: สีอัตลักษณ์ประจำธาตุอาหาร (Elemental Identity Base Colors)}
        \begin{itemize}
            \item \textbf{ไนโตรเจนรวม (Total N):} โทนสีฟ้าคราม (\texttt{\#00E5FF}) สื่อถึงบรรยากาศและคลอโรฟิลล์
            \item \textbf{ฟอสฟอรัส (Available P):} โทนสีส้ม/ทองอำพัน (\texttt{\#FF9100}) สื่อถึงพลังงานและการเจริญของราก
            \item \textbf{โพแทสเซียม (Available K):} \textbf{โทนสีแดง (Red/Crimson/Rose: \texttt{\#FF5252})} ตามข้อกำหนดของคณะผู้วิจัย เพื่อความชัดเจน โดดเด่น และสอดรับกับเส้นกราฟมาตรฐานการดูดกลืนแสง Ref-K
            \item \textbf{อินทรียวัตถุในดิน (Soil OM):} โทนสีเขียวมรกตสดใส (\texttt{\#69F0AE}) สื่อถึงความอุดมสมบูรณ์ทางชีวภาพ
        \end{itemize}
        \item \textbf{มิติที่ 2: การเปลี่ยนเฉดสีตามระดับการวิเคราะห์ 5 ระดับ (Nutrient-Specific 5-Level Shade Gradient)}
        ตัวเลขผลการวัดและแถบความคืบหน้า (Progress Bar) จะปรับเปลี่ยนเฉดสีและความอิ่มตัวตามระดับความอุดมสมบูรณ์ของดินจริง:
        \begin{itemize}
            \item \textbf{ต่ำมาก (Very Low):} เฉดสีพาสเทลอ่อน แสดงถึงความเบาบางและขาดแคลนของธาตุอาหาร (เช่น K: สีแดงอ่อนพาสเทล \texttt{\#FF8A80})
            \item \textbf{ต่ำ (Low):} เฉดสีสว่างระดับปานกลาง (เช่น K: สีแดงปะการัง \texttt{\#FF5252})
            \item \textbf{ปานกลาง (Moderate - เหมาะสม):} เฉดสีสดใส มีชีวิตชีวา (เช่น K: สีแดงทับทิมสด \texttt{\#FF1744})
            \item \textbf{สูง (High):} เฉดสีเข้มสด อิ่มตัวสมบูรณ์ (เช่น K: สีแดงเข้ม \texttt{\#D50000})
            \item \textbf{สูงมาก (Very High):} เฉดสีเข้มจัดลึก แสดงถึงการสะสมในปริมาณมาก (เช่น K: สีแดงไวน์เข้ม \texttt{\#B71C1C})
        \end{itemize}
        \item \textbf{มิติที่ 3: สีสถานะวินิจฉัยสุขภาพดินตามเกณฑ์สากล (Agronomic Diagnostic Traffic Light)}
        ป้ายระบุระดับ (Status Badge) บนมุมขวาของการ์ดเกจวัดและจุดอินดิเคเตอร์บนแถบ AR HUD แสดงสีเตือนภัยตามมาตรฐานปฐพีวิทยา:
        \begin{itemize}
            \item \textbf{ต่ำมาก:} สีแดงเตือนภัย (\texttt{\#FF4D4F}) บ่งชี้วิกฤตขาดธาตุ ต้องแก้ไขทันที
            \item \textbf{ต่ำ:} สีส้มอำพัน (\texttt{\#FFA940}) บ่งชี้ภาวะขาดแคลน ต้องเติมธาตุอาหารเสริม
            \item \textbf{ปานกลาง:} สีเขียวมรกต (\texttt{\#52C41A}) ระดับพอเหมาะ สมดุล และปลอดภัยที่สุด
            \item \textbf{สูง:} สีฟ้าสดใส (\texttt{\#1890FF}) บ่งชี้ความอุดมสมบูรณ์เพียงพอ
            \item \textbf{สูงมาก:} สีม่วงคราม (\texttt{\#722ED1}) บ่งชี้ภาวะล้นเกิน เสี่ยงต่อการขัดขวางการดูดซึมธาตุอื่น
        \end{itemize}
    \end{itemize}
\end{enumerate}

\section{ภาพรวมหน้าจอและเมนูการทำงานของแอปพลิเคชัน NPxAI}
แอปพลิเคชัน NPxAI เวอร์ชัน 1.2.0 ได้รับการออกแบบภายใต้หลักการ Human-Computer Interaction (HCI) และสถาปัตยกรรมคู่ขนานสองโหมด (Dual-Architecture) เพื่อให้เกษตรกรและนักวิจัยสามารถเข้าถึงการวิเคราะห์เคมีดินขั้นสูงได้อย่างสะดวก รวดเร็ว และแม่นยำสูง ระบบเมนูหลักแบ่งออกเป็น 4 ฟังก์ชันการทำงานที่ครอบคลุมตลอดกระบวนการวิเคราะห์ดิน

\subsection{เมนูที่ 1 การเชื่อมต่ออุปกรณ์และการสอบเทียบระบบ (Connection \& Calibration)}
หน้าจอแรกของแอปพลิเคชันทำหน้าที่เป็นศูนย์กลางการสื่อสารและควบคุมคุณภาพของระบบตรวจวัด (รูปที่ \ref{fig:app_screens_1_2} ซ้าย) ประกอบด้วยองค์ประกอบหลักดังต่อไปนี้
\begin{itemize}
    \item \textbf{ระบบเชื่อมต่อบลูทูธพลังงานต่ำ (BLE Device Status)} ตรวจจับและเชื่อมโยงสัญญาณกับชุดกล่องมืด Dark Chamber โดยอัตโนมัติ แสดงที่อยู่ MAC Address และค่าความแรงสัญญาณ RSSI
    \item \textbf{การตรวจวัดสุขภาพฮาร์ดแวร์ (Hardware Telemetry)} รายงานระดับพลังงานแบตเตอรี่ อุณหภูมิการทำงานของเซนเซอร์ และสถานะความเสถียรของแสงแบบเรียลไทม์
    \item \textbf{สวิตช์เลือกระบบฮาร์ดแวร์คู่ขนาน (Dual-Architecture Hardware Mode)} ผู้ใช้งานสามารถเลือกระหว่างโหมดพกพาประหยัด (NPxAI Lite: Smartphone Flash $45^\circ$) หรือโหมดความแม่นยำสูงห้องปฏิบัติการ (NPxAI Pro: 7-Band Multi-Spectral Chamber)
    \item \textbf{ปุ่มคำสั่งสอบเทียบระบบมาตรฐาน (System Calibration Hub)} ปุ่มคำสั่งสำหรับเริ่มกระบวนการสอบเทียบจุดมืด (Zero-Dark Calibration) และการสอบเทียบแผ่นเทียบขาวมาตรฐาน (White Reference Calibration)
\end{itemize}

\subsection{เมนูที่ 2 ระบบสแกนดินสดและการคัดเลือกโมเดลปัญญาประดิษฐ์ (Soil-ViT Scanner)}
หน้าจอหลักสำหรับการเก็บข้อมูลตัวอย่างดินภาคสนาม (รูปที่ \ref{fig:app_screens_1_2} ขวา) พัฒนาขึ้นด้วยสถาปัตยกรรม Edge Vision Computing ประกอบด้วย
\begin{itemize}
    \item \textbf{ป้ายระบุโหมดฮาร์ดแวร์บน HUD (Hardware Mode Badge)} แสดงสถานะโหมดปัจจุบันที่มุมบนซ้ายอย่างเด่นชัด ได้แก่ \texttt{[⚡ Lite (Flash 45°)]} หรือ \texttt{[🔬 Pro (Chamber)]}
    \item \textbf{สวิตช์เลือกโหมดฮาร์ดแวร์แบบ Segmented} ติดตั้งอยู่เหนือเมนูเลือกโมเดล AI ช่วยให้ผู้ปฏิบัติงานสลับโหมด Lite/Pro ได้ทันทีโดยไม่ต้องย้อนกลับไปหน้าตั้งค่า
    \item \textbf{ช่องมองภาพสดพร้อมเป้าเล็งเชิงแสง (Optical Target Reticle)} แสดงภาพตัวอย่างดินแบบเวลาจริง พร้อมกรอบพื้นที่สนใจ (Region of Interest: ROI) ขนาด $120 \times 120\text{ pixels}$ กึ่งกลางหน้าจอ ซึ่งเป็นตำแหน่งที่แสงตกกระทบสมมาตรตามเรขาคณิต CIE 45°/0°
    \item \textbf{ระบบวิเคราะห์วิดีโอสดแบบเรียลไทม์ (Live Video Edge AI Stream with AR HUD Overlay)}
    เมื่อผู้ใช้กดปุ่มวิดีโอ (Video Record / Live Stream Button) ระบบจะเปิดโหมดวิเคราะห์ภาพสดแบบไดนามิก โดยมีลักษณะการทำงานสำคัญดังนี้
    \begin{enumerate}
        \item \textbf{การอนุมานต่อเนื่องระดับขอบ (Rolling Edge Inference):} ปัญญาประดิษฐ์บนอุปกรณ์จะประมวลผลเฟรมภาพสดและสเปกตรัมทุก ๆ $650\text{ ms}$ อย่างต่อเนื่องโดยไม่มีอาการกระตุก
        \item \textbf{แถบสถานะ AR HUD แบบโปร่งใส (Live HUD Status Banner):} แสดงแถบข้อความโปร่งแสงซ้อนทับด้านล่างเป้าเล็ง พร้อมจุดกระพริบสีแดงระบุสถานะ \texttt{LIVE AI STREAM}
        \item \textbf{การแสดงค่าความเชื่อมั่นแบบเรียลไทม์ (Real-time Confidence Score):} แสดงเปอร์เซ็นต์ความเชื่อมั่นของการอนุมาน เช่น \texttt{Conf: 96.2\%} คำนวณจากค่า $R^2$ ของโมเดลร่วมกับความเสถียรของฟลักซ์ส่องสว่าง
        \item \textbf{ชุดตัวเลขโปร่งใส N-P-K-OM บนหน้าจอ (Floating Transparent Metric Badges):} แสดงผลลัพธ์ธาตุอาหารสดเป็นตัวเลขโปร่งใสคมชัด 4 ค่า ได้แก่ Total N (g/kg), Available P (mg/kg), Available K (mg/kg) และ Soil OM (\%) พร้อมรหัสสีประจำธาตุ
        \item \textbf{การควบคุมไฟฉายอัตโนมัติ (Hardware Torch Coupling):} ในโหมด NPxAI Lite เมื่อเริ่มสตรีมวิดีโอสด แอปพลิเคชันจะสั่งเปิดไฟฉายแฟลชสมาร์ทโฟนโดยอัตโนมัติ (\texttt{FLASH 45° ACTIVE}) เพื่อให้แสงผ่านท่อนำแสง $45^\circ$ และจะปิดไฟฉายทันทีเมื่อผู้ใช้กดหยุดสตรีม
    \end{enumerate}
    \item \textbf{แถบเลือกแบบจำลองปัญญาประดิษฐ์ (AI Model Selector)} ผู้ใช้งานสามารถเลือกเปลี่ยนสถาปัตยกรรมโมเดลได้ทันที 5 รูปแบบ ได้แก่ Soil-ViT, ResNet-18, LightGBM, Random Forest และ XGBoost
    \item \textbf{ชุดปุ่มสั่งการตรวจวัด 3 รูปแบบ} ปุ่มสแกนวิเคราะห์ดิน (Scan), ปุ่มบันทึกภาพนิ่ง (Photo Capture) และปุ่มสตรีมวิดีโอสด (Live Video Stream)
    \item \textbf{ระบบบันทึกพิกัดดาวเทียม GNSS อัตโนมัติ} ระบุพิกัดละติจูด-ลองจิจูด พร้อมข้อมูล Geotagging บันทึกลงในไฟล์ CSV ส่งออก
\end{itemize}

\subsection{เมนูที่ 3 หน้าจอรายงานผลวิเคราะห์ 4 พารามิเตอร์ดิน N-P-K-OM และกราฟสเปกตรัมการดูดกลืนแสง UV-VIS-IR}
หน้าจอรายงานผลลัพธ์การประเมินธาตุอาหารพืชแบบเรียลไทม์ (รูปที่ \ref{fig:app_screens_3_4} ซ้าย) ได้รับการออกแบบให้แสดงผลข้อมูลเชิงปริมาณและข้อมูลเชิงสเปกตรัมที่สมบูรณ์ โดยครอบคลุมทั้ง 3 ย่านคลื่นแม่เหล็กไฟฟ้า ได้แก่ ย่านอัลตราไวโอเลต (UV), ย่านแสงขาวที่ตามองเห็น (VIS) และย่านอินฟราเรดย่านใกล้ (IR / NIR)
\begin{itemize}
    \item \textbf{ป้ายระบุสถาปัตยกรรมฮาร์ดแวร์ในการวิเคราะห์ (Hardware Mode Header Badge)} แสดงแถบป้ายชัดเจนที่หัวการ์ดผลลัพธ์ เช่น \texttt{[⚡ NPxAI Lite: Flash 45° ($R^2 \approx 0.86-0.88$)]} หรือ \texttt{[🔬 NPxAI Pro: Multi-Spectral Chamber ($R^2 \approx 0.94-0.97$)]}
    \item \textbf{การ์ดชุดรายงาน 4 พารามิเตอร์ดิน (Symmetric 2x2 Grid Gauges)} แสดงค่า Total Nitrogen (g/kg), Available Phosphorus (mg/kg), Available Potassium (mg/kg) และ Soil Organic Matter (\%) พร้อมป้ายระบุระดับความอุดมสมบูรณ์ 5 ระดับตามเกณฑ์กรมพัฒนาที่ดิน (ต่ำมาก, ต่ำ, ปานกลาง, สูง, สูงมาก) จัดวางในรูปแบบ $2 \times 2$ อย่างสมดุลและสวยงาม ไร้ปัญหาข้อความล้นจอ
    \item \textbf{แถบจำแนกย่านคลื่นสเปกตรัม (UV $\cdot$ VIS $\cdot$ IR Spectrum Band Selector)} เพิ่มแถบเลือกและจำแนกย่านคลื่นเชิงแสง 3 กลุ่มหลัก ได้แก่
    \begin{itemize}
        \item \textbf{ย่าน UV (380--405 nm)} แถบสีม่วง วิเคราะห์การดูดกลืนสารอินทรีย์ฮิวมัส พันธะคอนจูเกต $C=C$ และไนโตรเจนอินทรีย์ (Organic N)
        \item \textbf{ย่าน VIS (420--700 nm)} แถบสีฟ้าและเขียว ตรวจวัดสารสีแคโรทีนอยด์ กรดฮิวมิก โครงสร้างเนื้อดิน และการเปลี่ยนระดับพลังงานชั้น $d-d$ transition ของสารประกอบเหล็กออกไซด์ $\text{Fe}^{3+}$ (Hematite) ซึ่งสัมพันธ์โดยตรงกับฟอสฟอรัสที่เป็นประโยชน์ รวมถึงการสะท้อนย่านเขียว $525\text{ nm}$ ของแร่โพแทสเซียม
        \item \textbf{ย่าน IR หรือ NIR (750--950 nm)} แถบสีส้มอินฟราเรด ตรวจจับโอเวอร์โทนที่ 3 ของพันธะ $O-H$ ในน้ำและความชื้นดิน การสั่นสะเทือนของโครงข่ายฟอสเฟตในดิน และโครงข่ายผลึกแร่ดินเหนียว 2:1 ที่เป็นแหล่งกักเก็บโพแทสเซียม
    \end{itemize}
    \item \textbf{กราฟสเปกตรัมแบบโต้ตอบพร้อมแถบสีแยกย่าน (Interactive Multi-Zone Canvas)} ตัวกราฟไฮไลต์พื้นหลังแยกย่าน UV (สีม่วง), VIS (สีฟ้า) และ IR (สีส้ม) พร้อมเส้นประแบ่งขอบเขตย่านคลื่น และมีปุ่มสลับมุมมองระหว่างค่าการสะท้อนแสง (\% Reflectance) และค่าการดูดกลืนแสงเชิงแสง (Absorbance คำนวณจาก $A = \log_{10}(1/R)$)
    \item \textbf{เส้นกราฟอ้างอิงมาตรฐานธาตุอาหารพืช N, P, K (Nutrient Standard Reference Curves)} เพื่อยกระดับความน่าเชื่อถือทางวิทยาศาสตร์ ระบบได้เพิ่มเส้นกราฟมาตรฐานการดูดกลืนและการสะท้อนของธาตุอาหารพืช 3 ธาตุหลัก ได้แก่
    \begin{itemize}
        \item \textbf{มาตรฐานไนโตรเจน (Ref-N เส้นประสีฟ้า Cyan)} จำลองสเปกตรัมสารอินทรีย์ไนโตรเจนและฮิวมัส มีค่าการดูดกลืนสูงเด่นชัดที่ $405\text{ nm}$ (UV Soret band) และพีคยกระดับที่ $940\text{ nm}$ จากโอเวอร์โทนพันธะ $\text{N-H}$
        \item \textbf{มาตรฐานฟอสฟอรัส (Ref-P เส้นประสีส้ม Amber)} จำลองสเปกตรัมสารประกอบฟอสเฟตที่จับกับเหล็กออกไซด์ ($\text{Fe-P}$) แสดงพีคดูดกลืนเด่นชัดที่ $630\text{ nm}$ ($d-d$ transition ของ $\text{Fe}^{3+}$) และ $850\text{ nm}$ ซึ่งตรงกับไหล่การสั่นสะเทือนของหมู่ฟอสเฟต
        \item \textbf{มาตรฐานโพแทสเซียม (Ref-K เส้นประสีม่วง Magenta)} จำลองสเปกตรัมโพแทสเซียมในโครงข่ายแร่ดินเหนียวชนิด 2:1 (Illite-Smectite matrix) แสดงจุดดูดกลืนที่ $525\text{ nm}$ และการดูดกลืนในย่าน NIR $850--940\text{ nm}$
    \end{itemize}
    \item \textbf{ชิปสลับการแสดงผลแบบอิสระ (Interactive Comparison Chips)} ผู้ใช้สามารถกดเลือกเปิดหรือปิดเส้นกราฟตัวอย่างดินจริง หรือเส้นมาตรฐาน N, P, K แต่ละเส้นได้อย่างอิสระ ทำให้สามารถเปรียบเทียบความสัมพันธ์ของสเปกตรัมดินกับธาตุอาหารแต่ละชนิดได้อย่างชัดเจน
    \item \textbf{แถบการ์ด HUD เปรียบเทียบค่าธาตุอาหาร (Multi-Element Diagnostic HUD)} เมื่อผู้ใช้สัมผัสเลือกความยาวคลื่นใด ๆ การ์ด HUD ด้านล่างจะแสดงข้อมูลเจาะลึกพร้อมแถบเปรียบเทียบค่าสเปกตรัมระหว่างตัวอย่างดินจริงกับค่ามาตรฐาน Ref-N, Ref-P และ Ref-K ณ ความยาวคลื่นนั้นทันที
    \item \textbf{การระบุจุดตรวจวัดและป้ายแท็กกำกับย่านคลื่น} ปุ่มเลือกความยาวคลื่นทั้ง 6 ช่องด้านล่างแกน X ติดตั้งป้ายกำกับย่าน [UV], [VIS], [IR] เด่นชัด
\end{itemize}

\section{ระเบียบวิธีการสอบเทียบมาตรฐานระบบตรวจวัด (System Calibration Protocol)}
เพื่อให้การตรวจวัดปริมาณไนโตรเจนและฟอสฟอรัสในดินด้วยหลักการสะท้อนแสงมีความถูกต้อง แม่นยำ และทวนสอบได้ตามมาตรฐานมาตรวิทยาเชิงแสง (Optical Metrology) แอปพลิเคชัน NPxAI ได้ติดตั้งระเบียบวิธีการสอบเทียบมาตรฐานสองจุด (Two-Point Radiometric Calibration Protocol) ร่วมกับการคำนวณแฟกเตอร์การปรับเทียบเฉพาะช่วงคลื่น (Wavelength-Specific Calibration Factor)

\subsection{หลักการทางคณิตศาสตร์และการชดเชยค่าทางแสง}
สัญญาณความเข้มแสงดิบ $I_{\text{meas}}(\lambda)$ ที่เซนเซอร์รับภาพ CMOS บันทึกได้ในแต่ละความยาวคลื่น จะประกอบด้วยผลรวมของแสงสะท้อนจริง สัญญาณรบกวนจากกระแสมืด (Dark Current Noise) และความไม่สม่ำเสมอของการตอบสนองของเซนเซอร์ การคำนวณค่าการสะท้อนแสงสัมพัทธ์ที่แท้จริง $R(\lambda)$ ทำได้ตามสมการ
\begin{equation}
R(\lambda) = \frac{I_{\text{meas}}(\lambda) - I_{\text{dark}}(\lambda)}{I_{\text{white}}(\lambda) - I_{\text{dark}}(\lambda)} \times R_{\text{white}}(\lambda)
\end{equation}
โดยที่
\begin{itemize}
    \item $I_{\text{meas}}(\lambda)$ คือ สัญญาณความเข้มแสงที่วัดได้จากตัวอย่างดิน
    \item $I_{\text{dark}}(\lambda)$ คือ สัญญาณความเข้มแสงที่วัดได้ในสภาวะมืดสนิท 0-Lux (Dark Baseline)
    \item $I_{\text{white}}(\lambda)$ คือ สัญญาณความเข้มแสงที่วัดได้จากแผ่นเทียบขาวมาตรฐาน
    \item $R_{\text{white}}(\lambda)$ คือ สัมประสิทธิ์การสะท้อนแสงของแผ่นเทียบขาวมาตรฐานที่สอบเทียบจากห้องปฏิบัติการสากล (PTFE Standard Reflectance $\approx 0.99$ หรือ $99\%$)
\end{itemize}

เมื่อได้ค่าการสะท้อนแสง $R(\lambda)$ แล้ว ระบบจะแปลงเป็นค่าการดูดกลืนแสงเชิงแสง (Optical Absorbance: $A$) ตามกฎของเบียร์-แลมเบิร์ต (Beer-Lambert Law) ดังสมการ
\begin{equation}
A(\lambda) = \log_{10}\left(\frac{1}{R(\lambda)}\right) = -\log_{10}(R(\lambda))
\end{equation}

\subsection{ขั้นตอนการปฏิบัติการสอบเทียบมาตรฐานภาคสนาม (Step-by-Step SOP)}
ผู้ปฏิบัติงานต้องทำการสอบเทียบระบบตรวจวัดตามลำดับขั้นตอนดังต่อไปนี้ อย่างน้อยสัปดาห์ละ 1 ครั้ง หรือทุกครั้งก่อนเริ่มรอบการตรวจวัดตัวอย่างในแปลงใหญ่
\begin{enumerate}
    \item \textbf{ขั้นตอนที่ 1 การสอบเทียบค่าความมืด (Zero-Dark Calibration)}
    \begin{itemize}
        \item นำสมาร์ทโฟนประกบเข้ากับแท่นยึดของกล่อง Dark Chamber โดยปิดฝากล่องและช่องใส่ถาดตัวอย่างให้สนิท ป้องกันแสงรั่วจากภายนอกเข้าสู่ห้องตรวจวัด
        \item เปิดแอปพลิเคชัน NPxAI ไปที่แท็บ ``เชื่อมต่อ \& คาลิเบรต'' และกดปุ่ม ``สอบเทียบจุดมืด (0-Lux)''
        \item ระบบจะทำการปิดแหล่งกำเนิดแสงทั้งหมด และสั่งการให้เซนเซอร์กล้องบันทึกค่าความเข้มแสงในความมืด $I_{\text{dark}}(\lambda)$ ครบทั้ง 7 แถบคลื่น เพื่อบันทึกเป็นค่า Offset ประจำวัน
    \end{itemize}
    \item \textbf{ขั้นตอนที่ 2 การสอบเทียบแผ่นเทียบขาวมาตรฐาน (White Reference Calibration)}
    \begin{itemize}
        \item วางแผ่นเทียบสะท้อนแสงสีขาวมาตรฐานทำจากวัสดุโพลีเตตระฟลูออโรเอทิลีน (PTFE White Diffuse Reflectance Standard) ความบริสุทธิ์สูง ลงในถาดวางตัวอย่าง
        \item สอดถาดเข้าสู่ตำแหน่งกึ่งกลางกล่องมืด และกดปุ่ม ``สอบเทียบแผ่นเทียบขาว (White Standard)'' บนแอปพลิเคชัน
        \item ระบบจะสั่งจุดหลอด LED หรือไฟแฟลชตามลำดับคลื่นแสง และบันทึกค่า $I_{\text{white}}(\lambda)$ พร้อมคำนวณค่าแฟกเตอร์การปรับเทียบ (Gain Calibration Factor: $k_\lambda$) ดังสมการ
        \begin{equation}
        k_\lambda = \frac{R_{\text{white\_spec}}(\lambda)}{I_{\text{white}}(\lambda) - I_{\text{dark}}(\lambda)}
        \end{equation}
        \item แอปพลิเคชันทำการบันทึกค่า $k_\lambda$ ลงในหน่วยความจำถาวร (Persistent Key-Value Store) ภายในสมาร์ทโฟน เพื่อนำไปใช้คูณชดเชยค่าการตรวจวัดดินจริงโดยอัตโนมัติ
    \end{itemize}
    \item \textbf{ขั้นตอนที่ 3 การตรวจยืนยันความเที่ยงตรงของระบบ (System Verification)}
    \begin{itemize}
        \item วางแผ่นเทียบสีเทากลางมาตรฐาน (Neutral 18\% Gray Card) ลงในถาด และสั่งสแกนทดสอบ 3 ครั้งติดต่อกัน
        \item แอปพลิเคชันจะคำนวณค่าสัมประสิทธิ์ความแปรปรวน (Coefficient of Variation: CV) ของค่าการสะท้อนแสง หากค่า $\text{CV} \le 1.5\%$ ระบบจะแสดงสถานะ ``การสอบเทียบสมบูรณ์ พร้อมปฏิบัติงาน''
    \end{itemize}
\end{enumerate}

\subsection{ระบบแจ้งเตือนการเสื่อมสภาพของหลอดกำเนิดแสง (LED Degradation Warning)}
ในการใช้งานระยะยาว ความเข้มแสงของหลอด LED และไฟฉายสมาร์ทโฟนอาจมีการลดทอนลงเนื่องจากความร้อนและอายุการใช้งาน ระบบแอปพลิเคชัน NPxAI ได้ติดตั้งอัลกอริทึมติดตามการเสื่อมสภาพของแหล่งกำเนิดแสง โดยเปรียบเทียบค่า $I_{\text{white}}(\lambda)$ ในการสอบเทียบครั้งล่าสุดกับค่าเริ่มต้นจากโรงงาน (Factory Baseline $I_{\text{factory}}(\lambda)$)
\begin{itemize}
    \item หากค่าความเข้มแสงลดลงเกินกว่า $15\%$ ในช่วงคลื่นใด ระบบจะแจ้งเตือนผู้ใช้งานให้ตรวจสอบความสะอาดของเลนส์และกระจกปิดหน้าเซนเซอร์
    \item หากค่าความเข้มแสงลดลงเกินกว่า $25\%$ ระบบจะระงับการสแกนและแนะนำให้ทำการเปลี่ยนชุดโมดูล LED ใหม่ เพื่อป้องกันความคลาดเคลื่อนในการทำนายธาตุอาหารของโมเดลปัญญาประดิษฐ์
\end{itemize}

\chapter{ระบบการ์ดเทียบสีมาตรฐานและการวิเคราะห์ปริภูมิสีดิจิทัล}

\section{ความสำคัญของสีและการวิเคราะห์สเปกโตรโฟโตเมทรีในงานวิจัยปฐพีวิทยา}
สีของดิน (Soil Color) เป็นหนึ่งในสมบัติทางสัณฐานวิทยาที่สำคัญที่สุดทางปฐพีวิทยาที่บ่งบอกถึงปริมาณอินทรียวัตถุในดิน (Soil Organic Matter หรือ SOM), ระดับการเกิดออกซิเดชันของสารประกอบเหล็ก, สภาพการระบายน้ำและการถ่ายเทอากาศ, ตลอดจนศักยภาพความอุดมสมบูรณ์ของธาตุอาหารพืช การประยุกต์ใช้การประมวลผลภาพดิจิทัล (Digital Image Processing) ร่วมกับปัญญาประดิษฐ์บนอุปกรณ์เคลื่อนที่ จำเป็นต้องมีระบบเทียบเคียงกับชุดสีมาตรฐานสากล เพื่อแปลงค่าระดับสีดิจิทัล (Digital Color Values) ไปสู่ความเข้มข้นของธาตุอาหารและพารามิเตอร์เคมีดินได้อย่างแม่นยำ

ในระบบแอปพลิเคชัน NPxAI ได้นำปริภูมิสี (Color Spaces) 3 รูปแบบหลักมาใช้ในกระบวนการอนุมาน ได้แก่
\begin{enumerate}
    \item \textbf{ปริภูมิสี sRGB} ค่าความเข้มแสงสามแชนเนล ($R, G, B \in [0, 255]$) ที่ได้จากเซนเซอร์รับภาพ CMOS สำหรับการวิเคราะห์คุณลักษณะพื้นผิวและการสกัดลวดลาย
    \item \textbf{ปริภูมิสี HSV} ค่าองศาของสี (Hue, $H \in [0^\circ, 360^\circ]$), ความอิ่มตัวของสี (Saturation, $S \in [0\%, 100\%]$) และความสว่าง (Value, $V \in [0\%, 100\%]$) ซึ่งสะท้อนความมืดสว่างของฮิวมัสในดินอย่างเป็นอิสระต่อความเข้มแสง
    \item \textbf{ปริภูมิสีสากลมันเซลล์ (Munsell Color System)} มาตรฐานปฐพีวิทยาระดับสากล (USDA-FAO) ที่จำแนกตาม Hue, Value และ Chroma
\end{enumerate}

\subsection{สมการการแปลงปริภูมิสีในเอนจิน Pure Dart}
เอนจินบนขอบของ NPxAI ทำการแปลงสัญญาณจากพิกัด sRGB ที่ผ่านการปรับเทียบมาตรฐาน เข้าสู่ปริภูมิสี HSV และ CIE $L^*a^*b^*$ ตามสมการ

\begin{equation}
V = \max(R, G, B), \quad S = \begin{cases} 0 & \text{ถ้า } V = 0 \\ \frac{V - \min(R, G, B)}{V} & \text{ถ้า } V > 0 \end{cases}
\end{equation}

\begin{equation}
H = \begin{cases}
0^\circ & \text{ถ้า } S = 0 \\
60^\circ \times \frac{G - B}{V - \min(R, G, B)} \pmod{360^\circ} & \text{ถ้า } V = R \\
60^\circ \times \left(2 + \frac{B - R}{V - \min(R, G, B)}\right) & \text{ถ้า } V = G \\
60^\circ \times \left(4 + \frac{R - G}{V - \min(R, G, B)}\right) & \text{ถ้า } V = B
\end{cases}
\end{equation}

การนำค่าพิกัดสี $(H, S, V)$ และ $(L^*, a^*, b^*)$ เข้าสู่โครงข่ายประสาทเทียม ทำให้โมเดลสามารถจำแนกระดับฮิวมัส, ค่า pH และความเข้มข้นของธาตุอาหารได้อย่างแม่นยำ แม้สภาพแสงภายนอกจะมีความแปรปรวนก็ตาม

\section{รากฐานทางฟิสิกส์ของการดูดกลืนแสงและอันตรกิริยาในดิน}
การตรวจวัดคุณสมบัติของดินด้วยเทคนิคสเปกโทรสโกปีการสะท้อนแบบกระจาย (Diffuse Reflectance Spectroscopy: DRS) ครอบคลุมย่านคลื่นรังสีอัลตราไวโอเลต แสงที่ตามองเห็น อินฟราเรดย่านใกล้ และอินฟราเรดย่านคลื่นสั้น (UV-Vis-NIR-SWIR ในช่วงความยาวคลื่น $350 - 2500\text{ nm}$) ได้รับการยอมรับในวงการปฐพีวิทยาระดับสากลว่าเป็นเทคนิคที่ไม่ทำลายตัวอย่าง รวดเร็ว และไม่ต้องใช้สารเคมีอันตราย (Stenberg et al., 2010; Viscarra Rossel \& Behrens, 2010)

อันตรกิริยาระหว่างคลื่นแม่เหล็กไฟฟ้ากับอนุภาคดินจำแนกตามกลไกทางฟิสิกส์ได้ 2 ระดับหลัก

\begin{enumerate}
    \item \textbf{การเปลี่ยนระดับพลังงานอิเล็กตรอน (Electronic Transitions)} เกิดขึ้นในย่านรังสีอัลตราไวโอเลตและแสงที่ตามองเห็น ($350 - 700\text{ nm}$) เป็นผลจากการกระตุ้นอิเล็กตรอนในวงโคจร $d$ ของไอออนโลหะทรานซิชัน โดยเฉพาะเหล็ก ($\text{Fe}^{3+}$ และ $\text{Fe}^{2+}$) ที่เป็นองค์ประกอบของแร่เหล็กออกไซด์ ตลอดจนการถ่ายโอนประจุ (Charge Transfer) ในโมเลกุลสารอินทรีย์ฮิวมัส
    
    \item \textbf{การสั่นของพันธะโมเลกุล (Molecular Vibrations)} เกิดขึ้นจากการยืดตัว (Stretching) และการบิดงอ (Bending) ของพันธะเคมีที่มีโมเมนต์ไดโพล เช่น $\text{O-H}$, $\text{C-H}$, $\text{N-H}$, $\text{C=O}$ และ $\text{Al-OH}$ โดยการสั่นระดับพื้นฐาน (Fundamental Vibrations) เกิดขึ้นในย่านอินฟราเรดย่านกลาง (Mid-Infrared: MIR ช่วงความยาวคลื่น $2500 - 25000\text{ nm}$) ในขณะที่การสั่นที่ตรวจวัดได้ในย่าน NIR-SWIR ($700 - 2500\text{ nm}$) เป็นผลมาจากคุณสมบัติแอนฮาร์มอนิก (Anharmonicity) ของโมเลกุล ทำให้เกิดแถบโอเวอร์โทน (Overtone Bands) และแถบรวมการสั่น (Combination Bands) ดังสมการพลังงานการสั่น
\end{enumerate}

\begin{equation}
E_v = h\nu_0 \left(v + \frac{1}{2}\right) - h\nu_0 \chi_e \left(v + \frac{1}{2}\right)^2
\end{equation}

เมื่อ $v$ คือเลขควอนตัมการสั่น ($\nu = 0, 1, 2, \dots$), $\nu_0$ คือความถี่การสั่นมูลฐาน และ $\chi_e$ คือค่าคงที่แอนฮาร์มอนิก การเปลี่ยนระดับจาก $v = 0 \rightarrow 2$ ทำให้เกิดโอเวอร์โทนขั้นที่หนึ่ง (First Overtone: ความยาวคลื่นประมาณกึ่งหนึ่งของความถี่มูลฐาน) และ $v = 0 \rightarrow 3$ ก่อให้เกิดโอเวอร์โทนขั้นที่สอง (Second Overtone)

\section{งานวิจัยสเปกตรัมการดูดกลืนของไนโตรเจนและอินทรียวัตถุ}
ไนโตรเจนในดินมีความสำคัญยิ่งยวดต่อการเจริญเติบโตของพืช ในดินเกษตรกรรมส่วนใหญ่ มากกว่าร้อยละ 90 ถึง 95 ของไนโตรเจนทั้งหมด (Total Nitrogen: TN) อยู่ในรูปสารประกอบอินทรีย์โมเลกุลใหญ่ (Organic N) ที่ผูกพันอยู่กับอินทรียวัตถุในดิน (Soil Organic Matter: SOM) และคาร์บอนอินทรีย์ในดิน (Soil Organic Carbon: SOC) เช่น กรดอะมิโน โปรตีน ลิกนิน และสารฮิวมิก (Chang et al., 2001; Ben-Dor \& Banin, 1995)

จากรายงานการวิจัยระดับโลกโดย Stenberg et al. (2010) และ Viscarra Rossel et al. (2006) การดูดกลืนแสงที่สัมพันธ์กับไนโตรเจนและคาร์บอนอินทรีย์มีแถบคลื่นจำเพาะดังนี้

\begin{enumerate}
    \item \textbf{แถบการดูดกลืนพันธะ $\text{N-H}$ (Amide and Amino Groups)}
    \begin{itemize}
        \item \textbf{1510 nm} โอเวอร์โทนขั้นที่หนึ่งของการยืดตัวของพันธะไนโตรเจน-ไฮโดรเจน ($2\nu(\text{N-H})$) ที่พบในสายพอลิเพปไทด์และสารอินทรีย์ไนโตรเจน
        \item \textbf{2050--2060 nm} แถบรวมการสั่นระหว่างการยืดตัวของ $\text{N-H}$ และการบิดงอของโครงสร้างเอไมด์ ($\nu(\text{N-H}) + \text{Amide II}$)
        \item \textbf{2130--2180 nm} แถบรวมการสั่นของโปรตีนและกรดอะมิโนอิสระในสารอินทรีย์ดิน ซึ่งมีความสัมพันธ์โดยตรงกับระดับไนโตรเจนทั้งหมด
    \end{itemize}
    
    \item \textbf{แถบการดูดกลืนพันธะ $\text{C-H}$ (Aliphatic and Aromatic Hydrocarbons)}
    \begin{itemize}
        \item \textbf{1180--1200 nm} โอเวอร์โทนขั้นที่สองของการยืดตัวของพันธะ $\text{C-H}$ ($3\nu(\text{C-H})$)
        \item \textbf{1720--1765 nm} โอเวอร์โทนขั้นที่หนึ่งของการยืดตัวของกลุ่มเมทิลีนและเมทิล ($2\nu(\text{C-H})$ ในหมู่อะลิฟาติก $-\text{CH}_2-$ และ $-\text{CH}_3-$)
        \item \textbf{2300--2350 nm} แถบรวมการสั่นของการยืดตัวและการบิดงอของ $\text{C-H}$ ร่วมกับโครงสร้างกรดฮิวมิก
    \end{itemize}
    
    \item \textbf{การดูดกลืนในย่านแสงที่ตามองเห็น ($400 - 700\text{ nm}$)}
    สารอินทรีย์ฮิวมิกทำให้เกิดการดูดกลืนแสงอย่างกว้างขวางตลอดช่วงคลื่นแสงที่ตามองเห็น ส่งผลให้ดินที่มีอินทรียวัตถุสูงมีสีเข้มดำ (Low Lightness / Value) งานวิจัยของ Mouazen et al. (2010) ยืนยันว่าการลดลงของค่าความสะท้อนแสงในช่วง $450 - 650\text{ nm}$ มีสหสัมพันธ์ทางสถิติสูงมาก ($R^2 > 0.85$) กับปริมาณ Total N และ SOM
\end{enumerate}

\section{งานวิจัยสเปกตรัมการดูดกลืนของฟอสฟอรัส}
การตรวจวัดฟอสฟอรัสที่เป็นประโยชน์ (Available Phosphorus: Ava P) ในดินด้วยเทคนิคสเปกโทรสโกปีถือเป็นหนึ่งในหัวข้อวิจัยที่ท้าทายที่สุด เนื่องจากไอออนออร์โธฟอสเฟต ($\text{H}_2\text{PO}_4^-$ และ $\text{HPO}_4^{2-}$) มีความเข้มข้นในดินค่อนข้างต่ำ (มักอยู่ในช่วง $5 - 80\text{ mg/kg}$ หรือส่วนในล้านส่วน ppm) และไม่มีแถบการสั่นระดับพื้นฐานที่โดดเด่นในย่าน NIR เหมือนน้ำหรือสารอินทรีย์ (Soriano-Disla et al., 2014; Malley et al., 2004)

อย่างไรก็ตาม งานวิจัยทางปฐพีวิทยาและเคมีดินค้นพบกลไกการตรวจวัดทางอ้อมผ่านสหสัมพันธ์ร่วมของแร่ (Indirect Mineral Covariance Mechanism) ดังนี้

\begin{enumerate}
    \item \textbf{การจับยึดกับแร่เหล็กออกไซด์ (Iron Oxide Fixation)}
    ในดินเขตร้อนชื้นที่มีสภาพเป็นกรด เช่น ดินสวนผลไม้ในจังหวัดจันทบุรีและตราด ฟอสฟอรัสส่วนใหญ่จะถูกตรึงแน่นบนพื้นผิวของแร่เกอไทต์ (Goethite: $\alpha\text{-FeOOH}$) และแร่ฮีมาไทต์ (Hematite: $\alpha\text{-Fe}_2\text{O}_3$) ในรูปสารประกอบเชิงซ้อนวงใน (Inner-Sphere Complexation) ซึ่งแร่เหล็กเหล่านี้มีแถบการดูดกลืนคลื่นที่ชัดเจนมาก
    \begin{itemize}
        \item \textbf{เกอไทต์ (Goethite)} มีแถบการดูดกลืนที่ $480\text{ nm}$ และแถบกว้างที่ $920\text{ nm}$ เกิดจากการเปลี่ยนระดับพลังงานสนามผลึก (Crystal Field Transition) ของไอออน $\text{Fe}^{3+}$ จากสถานะพื้น $^6A_1$ ไปสู่ $^4T_1$
        \item \textbf{ฮีมาไทต์ (Hematite)} มีแถบการดูดกลืนที่ $530--550\text{ nm}$ และ $860--880\text{ nm}$ จากการเปลี่ยนระดับพลังงาน $^6A_1 \rightarrow\ ^4T_2$
    \end{itemize}
    เมื่อฟอสเฟตเข้าจับกับพื้นผิวของออกไซด์เหล่านี้ จะทำให้เกิดการบิดเบือนของโครงสร้างผลึกผิวหน้าและส่งผลให้เกิดการเลื่อนตำแหน่ง (Spectral Shift) ของความชันเส้นสะท้อนแสงในช่วง $650 - 950\text{ nm}$ (Mouazen et al., 2010)
    
    \item \textbf{การจับยึดกับแร่ดินเหนียวเคโอลิไนต์และอะลูมิเนียม}
    ฟอสเฟตสร้างพันธะกับอะลูมิเนียมไฮดรอกไซด์ ($\text{Al-OH}$) ในแร่เคโอลิไนต์ ส่งผลกระทบต่อความเข้มข้นสัมพัทธ์ของแถบการดูดกลืน $\text{Al-OH}$ ที่ความยาวคลื่น $2206\text{ nm}$
    
    \item \textbf{ฟอสฟอรัสในรูปอินทรีย์ (Organic Phosphorus)}
    ฟอสฟอรัสประมาณร้อยละ 30 ถึง 65 ในดินชั้นบนอยู่ในรูปสารประกอบอินทรีย์ฟอสเฟต เช่น ไฟเตตและฟอสโฟลิพิด ซึ่งมีสหสัมพันธ์ร่วมกับแถบการสั่นของคาร์บอนอินทรีย์ที่ $1720\text{ nm}$ และ $2150\text{ nm}$
\end{enumerate}

ระบบ NPxAI จึงนำหลักการทางวิทยาศาสตร์นี้มาประยุกต์ใช้ โดยกำหนดความยาวคลื่นของหลอด LED แถบ $525\text{ nm}$, $630\text{ nm}$, $850\text{ nm}$ และ $940\text{ nm}$ เพื่อดักจับการเปลี่ยนแปลงคุณลักษณะของแร่เหล็กออกไซด์ที่ตรึงฟอสฟอรัสไว้ ทำให้แบบจำลองปัญญาประดิษฐ์สามารถสกัดสัญญาณแฝงของ Available P ออกมาได้อย่างแม่นยำ

\section{งานวิจัยสเปกตรัมการดูดกลืนของโพแทสเซียม แคลเซียม และแมกนีเซียม}
โพแทสเซียมที่เป็นประโยชน์ (Available K หรือ Exchangeable $\text{K}^+$) แคลเซียม ($\text{Ca}^{2+}$) และแมกนีเซียม ($\text{Mg}^{2+}$) จัดเป็นไอออนเดี่ยว (Monoatomic Cations) ซึ่งโดยคุณสมบัติทางควอนตัมเชิงฟิสิกส์แล้ว ไอออนเดี่ยวไม่มีพันธะโควาเลนต์คู่ จึงไม่มีการสั่นยืดหรือบิดงอโมเลกุลในย่านอินฟราเรดโดยตรง (Ben-Dor \& Banin, 1995)

การทำนายโพแทสเซียม แคลเซียม และแมกนีเซียมในงานวิจัยสเปกโทรสโกปีระดับสากล จึงอาศัยกลไกทางอ้อมผ่านสิ่งแวดล้อมทางเคมีฟิสิกส์ของดิน (Indirect Physico-Chemical Environment) ดังแสดงต่อไปนี้

\begin{enumerate}
    \item \textbf{แร่ต้นกำเนิดโพแทสเซียม (K-bearing Minerals)}
    โพแทสเซียมในดินสัมพันธ์อย่างลึกซึ้งกับแร่กลุ่มฟิลโลซิลิเกตและเฟลด์สปาร์ เช่น แร่อิลไลต์ (Illite) มัสโคไวต์ (Muscovite) และโพแทสเซียมเฟลด์สปาร์ ซึ่งแร่เหล่านี้มีพันธะ $\text{Al-Al-OH}$ และ $\text{Al-Mg-OH}$ ที่ดูดกลืนแสงเด่นชัดที่ความยาวคลื่น $2200--2210\text{ nm}$ และ $2340\text{ nm}$
    
    \item \textbf{การดูดซับบนอนุภาคคอลลอยด์และความจุการแลกเปลี่ยนแคตไอออน (CEC)}
    ปริมาณ $\text{K}^+$, $\text{Ca}^{2+}$, $\text{Mg}^{2+}$ ที่ดูดซับอยู่บนผิวหน้าของคอลลอยด์ดินเหนียวและฮิวมัส แปรผันตรงกับพื้นที่ผิวจำเพาะและความจุแลกเปลี่ยนประจุบวก (Cation Exchange Capacity: CEC) ซึ่งแสดงสัญญาณดูดกลืนผ่านแถบน้ำที่จับอยู่กับไอออนและแถบไฮดรอกซิลของแร่ดินเหนียวที่ $1400\text{ nm}$, $1900\text{ nm}$ และ $2200\text{ nm}$ (Chang et al., 2001)
    
    \item \textbf{การรบกวนโครงสร้างชั้นน้ำชุ่มชื้น (Hydration Shell Perturbation)}
    แคตไอออน $\text{K}^+$ มีผลทำให้โครงสร้างพันธะไฮโดรเจนของโมเลกุลน้ำรอบตัวมันเกิดการบิดเบือน ส่งผลให้แถบการดูดกลืนของน้ำที่ $1450\text{ nm}$ และ $1940\text{ nm}$ เกิดการเลื่อนตำแหน่งเล็กน้อย (Wavelength Shift) ซึ่งอัลกอริทึมปัญญาประดิษฐ์และ PLSR สามารถตรวจจับรูปแบบการเลื่อนตัวนี้ได้
    
    \item \textbf{แคลเซียมและแมกนีเซียมคาร์บอเนต}
    ในดินที่มีหินปูนหรือโดโลไมต์ แคลเซียมและแมกนีเซียมจะแสดงแถบการดูดกลืนของกลุ่มคาร์บอเนต ($\text{CO}_3^{2-}$) ที่ความยาวคลื่น $2330--2340\text{ nm}$ และ $2500\text{ nm}$ อย่างเด่นชัด
\end{enumerate}

\section{แถบสเปกตรัมรบกวนหลัก ความชื้นในดินและแร่ดินเหนียว}
ในการวัดสเปกตรัมดินจริงในแปลงเกษตรกรรม ปัจจัยแทรกซ้อนที่รุนแรงที่สุดคือ ความชื้นในดิน (Soil Moisture Content) และ ชนิดของแร่ดินเหนียว (Clay Minerals) ซึ่งมีแถบการดูดกลืนที่กว้างและมีกำลังแรงกว่าสัญญาณธาตุอาหารหลายเท่าตัว

\begin{enumerate}
    \item \textbf{แถบการดูดกลืนของน้ำในดิน ($\text{H}_2\text{O}$ Absorption)}
    \begin{itemize}
        \item \textbf{960 nm} โอเวอร์โทนขั้นที่สองของการยืดตัวของพันธะ $\text{O-H}$ ในโมเลกุลน้ำอิสระ ($3\nu(\text{O-H})$)
        \item \textbf{1450 nm} โอเวอร์โทนขั้นที่หนึ่งของการยืดตัวของพันธะ $\text{O-H}$ ($2\nu_3$ และ $\nu_1 + \nu_3$)
        \item \textbf{1940 nm} แถบรวมการสั่นระหว่างการบิดงอและการยืดตัวแบบไม่สมมาตร ($\nu_2 + \nu_3$) ถือเป็นพีคการดูดกลืนน้ำที่รุนแรงที่สุดในย่าน NIR
    \end{itemize}
    เมื่อดินมีความชื้นสูง ความสะท้อนแสงโดยรวม (Albedo) ของดินจะลดลงอย่างมากทั่วทั้งสเปกตรัม และพีคที่ $1450\text{ nm}$ และ $1940\text{ nm}$ จะขยายกว้างจนบดบังแถบการดูดกลืนของ $\text{N-H}$ และ $\text{C-H}$
    
    \item \textbf{แถบการดูดกลืนของหมู่ไฮดรอกซิลในแร่ดินเหนียว (Structural O-H)}
    \begin{itemize}
        \item \textbf{1400--1415 nm} การสั่นของ $\text{O-H}$ ในโครงตาข่ายผลึกของแร่เคโอลิไนต์และมอนต์มอริลโลไนต์
        \item \textbf{2200--2210 nm} การสั่นแบบผสมผสานของพันธะ $\text{Al-OH}$ (แร่อะลูมิโนซิลิเกต)
        \item \textbf{2280--2300 nm} การสั่นแบบผสมผสานของพันธะ $\text{Fe-OH}$
        \item \textbf{2320--2350 nm} การสั่นแบบผสมผสานของพันธะ $\text{Mg-OH}$
    \end{itemize}
\end{enumerate}

เพื่อขจัดสัญญาณรบกวนของความชื้นและแร่ดินเหนียว ระบบประมวลผลสัญญาณสเปกตรัมใน NPxAI จึงใช้กระบวนการเตรียมข้อมูลล่วงหน้า (Spectral Preprocessing Pipeline) ประกอบด้วย การแปลงอนุพันธ์อันดับหนึ่ง (Savitzky-Golay First Derivative), การปรับค่ามาตรฐานความแปรปรวนปกติ (Standard Normal Variate: SNV) และการชดเชยการกระเจิงแสงแบบคูณ (Multiplicative Scatter Correction: MSC) เพื่อแยกสัญญาณธาตุอาหารจำเพาะออกจากอิทธิพลของความชื้น

\chapter{ซอร์สโค้ดแบบจำลองปัญญาประดิษฐ์บนขอบ}

\begin{dartcode}[เอนจินการคำนวณแบบจำลองปัญญาประดิษฐ์หลากสถาปัตยกรรม (Pure Dart)]
class MultiModelEdgePredictor {
  // Multi-Model Edge Inference Switching
  NutrientPrediction predict({
    required SpectralSignature signature,
    required AiModelType modelType,
  }) {
    switch (modelType) {
      case AiModelType.cnnResNet:
        return _predictCnnResNet(signature);
      case AiModelType.randomForest:
        return _predictRandomForest(signature);
      case AiModelType.annPerceptron:
        return _predictAnnPerceptron(signature);
      case AiModelType.svrRbf:
        return _predictSvrRbf(signature);
      case AiModelType.plsrChemometrics:
        return _predictPlsr(signature);
    }
  }

  NutrientPrediction _predictAnnPerceptron(SpectralSignature sig) {
    final List<double> x = sig.toFeatureVector();
    double nSum = -0.42;
    for (int i = 0; i < x.length; i++) nSum += x[i] * _annWeightsN[i];
    final double predN = 0.45 + (2.65 / (1.0 + exp(-nSum * 0.82)));

    double pSum = 3.8;
    for (int i = 0; i < x.length; i++) pSum += x[i] * _annWeightsP[i];
    final double predP = max(2.5, pSum);

    return NutrientPrediction(
      totalNitrogen: predN,
      availablePhosphorus: predP,
      confidenceScore: 0.945,
    );
  }
}
\end{dartcode}
