คู่มือฉบับสมบูรณ์นี้จัดทำขึ้นเพื่อเป็นเอกสารทางวิชาการและคู่มือการปฏิบัติงานเชิงวิศวกรรมสำหรับโครงการวิจัยเรื่อง ``การพัฒนาชุดวิเคราะห์ปริมาณไนโตรเจนและฟอสฟอรัสในดินแบบพกพาด้วยหลักการสะท้อนแสงร่วมกับปัญญาประดิษฐ์ (NPxAI)'' ภายใต้แผนงานวิจัยบูรณาการเทคโนโลยีจุลชีววิทยาและปัญญาประดิษฐ์เพื่อการจัดการธาตุอาหารพืชอย่างยั่งยืนในพื้นที่เกษตรกรรมจังหวัดจันทบุรี มหาวิทยาลัยราชภัฏรำไพพรรณี

\chapter{ความเป็นมาและรากฐานทางทฤษฎี}

\section{ความเป็นมาและความสำคัญของปัญหา}
ดินในพื้นที่เกษตรกรรมของจังหวัดจันทบุรีและตราด โดยเฉพาะสวนทุเรียน มังคุด และเงาะ ประสบปัญหาการสะสมของธาตุอาหารไม่สมดุลจากการใช้ปุ๋ยเคมีในปริมาณสูงติดต่อกันเป็นเวลานาน การส่งตัวอย่างดินไปตรวจวิเคราะห์ในห้องปฏิบัติการมาตรฐานใช้เวลานาน 7 ถึง 14 วัน และมีค่าใช้จ่ายสูง ทำให้เกษตรกรขาดข้อมูลประกอบการตัดสินใจแบบทันท่วงที ส่งผลให้เกิดการสะสมของฟอสฟอรัสตกค้างที่ไม่เป็นประโยชน์ และเกิดการชะล้างไนโตรเจนลงสู่แหล่งน้ำธรรมชาติ

งานวิจัยนี้จึงมุ่งพัฒนานวัตกรรมเครื่องมือวิเคราะห์ดินแบบพกพาโดยใช้เทคนิค Visible and Near-Infrared Diffuse Reflectance Spectroscopy ร่วมกับปัญญาประดิษฐ์บนอุปกรณ์เคลื่อนที่ เพื่อให้เกษตรกรทราบปริมาณไนโตรเจนทั้งหมด (Total Nitrogen) และฟอสฟอรัสที่เป็นประโยชน์ (Available Phosphorus) ในแปลงปลูกได้ทันทีภายใน 3 วินาที พร้อมเชื่อมโยงคำแนะนำชีวภัณฑ์จุลินทรีย์ดินท้องถิ่น

\section{ทฤษฎีการสะท้อนแสงแบบกระจายและพันธะโมเลกุลในดิน}
เมื่อลำแสงตกกระทบลงบนผิวหน้าของอนุภาคดิน แสงจะเกิดการสะท้อนสองลักษณะ ได้แก่ การสะท้อนแบบสเปคิวลาร์ (Specular Reflection) ที่สะท้อนตามกฎการสะท้อนเชิงเรขาคณิต และการสะท้อนแบบกระจาย (Diffuse Reflectance) ที่แทรกซึมเข้าไปในเนื้อดินแล้วสะท้อนกลับออกมาหลังจากเกิดปฏิสัมพันธ์กับการดูดกลืนแสงของโมเลกุล

\end{figure}

ปริมาณการดูดกลืนแสงและค่าความสะท้อนสัมพันธ์ ($R_\lambda$) เป็นไปตามทฤษฎีคูเบลกา-มองค์ (Kubelka-Munk Theory) ดังสมการ

\begin{equation}
F(R_\infty) = \frac{(1 - R_\infty)^2}{2 R_\infty} = \frac{K}{S}
\end{equation}

โดย $K$ คือสัมประสิทธิ์การดูดกลืนแสง (Absorption Coefficient) และ $S$ คือสัมประสิทธิ์การกระเจิงแสง (Scattering Coefficient) ซึ่งแปรผันตามขนาดของอนุภาคดินและความชื้น

\section{การไขความกระจ่างทางวิทยาศาสตร์ ความสัมพันธ์ระหว่าง Total N และ Available P}
ในการพัฒนาแบบจำลองระยะแรก มักพบข้อสงสัยว่าเหตุใดจึงตรวจวัดค่าไนโตรเจนทั้งหมด (Total N) ได้อย่างรวดเร็ว ในขณะที่ฟอสฟอรัสที่เป็นประโยชน์ (Available P) มีความซับซ้อนและตรวจจับได้ยากกว่ามาก ข้อเท็จจริงทางฟิสิกส์สเปกโทรสโกปีอธิบายได้ดังนี้

\begin{enumerate}
    \item \textbf{ไนโตรเจนทั้งหมด (Total N)} ไนโตรเจนมากกว่า 90\% ในดินเกษตรกรรมผูกพันอยู่กับอินทรียวัตถุในดิน (Soil Organic Matter หรือ SOM) ซึ่งประกอบด้วยพันธะ C-H, N-H และ O-H อินทรียวัตถุนี้ส่งผลโดยตรงต่อค่าความมืดสว่าง (Value / Brightness) และความเข้มสีของดินอย่างชัดเจนในย่านแสงที่ตามองเห็น ($400 - 700\text{ nm}$) และย่านอินฟราเรดย่านใกล้ $850\text{ nm}$ จึงทำให้ระบบสามารถประเมินค่าทางอ้อม (Colorimetric Proxy) ได้อย่างแม่นยำแม้ใช้เพียงเซนเซอร์ RGB
    
    \item \textbf{ฟอสฟอรัสที่เป็นประโยชน์ (Available P)} ฟอสฟอรัสในดินไม่ได้เป็นเม็ดสีที่ให้ค่าสีจำเพาะต่อสายตามนุษย์ แต่มักอยู่ในรูปของสารประกอบออร์โธฟอสเฟตที่จับตัวอยู่กับสารประกอบเหล็กออกไซด์ (Iron Oxides) และอะลูมิเนียมในดินกรด การตรวจวัดฟอสฟอรัสจึงต้องการการดูดกลืนแสงในช่วงคลื่นจำเพาะ ได้แก่ $525\text{ nm}$ และย่านอินฟราเรดย่านใกล้ $940\text{ nm}$ ซึ่งเกินขอบเขตที่แสงขาวธรรมดาจะให้ข้อมูลได้โดยตรง
\end{enumerate}

\chapter{ฟิสิกส์เชิงแสงและสถาปัตยกรรมฮาร์ดแวร์}

\section{การควบคุมแสงรบกวน 0-Lux และเรขาคณิตเชิงแสง CIE 45°/0°}
การตรวจวัดการสะท้อนแสงในแปลงเกษตรกรรมจำเป็นต้องควบคุมสภาพแวดล้อมให้มืดสนิท (0-Lux Ambient Light) เพื่อป้องกันแสงแดดและแสงหลอดไฟภายนอกรบกวน กล่องมืด (Dark Chamber) จึงถูกออกแบบตามมาตรฐาน CIE 45°/0° โดยจัดตำแหน่งแหล่งกำเนิดแสงทำมุม 45 องศากับแนวตั้งฉากของผิวหน้าดิน และติดตั้งกล้องสมาร์ทโฟนไว้ที่แนวตั้งฉาก 0 องศา การจัดมุมนี้ทำให้แสงสะท้อนผิวหน้าแบบกระจก (Specular Glare) สะท้อนออกไปในทิศทาง 45 องศาฝั่งตรงข้าม และไม่เข้าสู่หน้าเลนส์กล้อง ทำให้กล้องตรวจวัดเฉพาะแสงสะท้อนแบบกระจาย (Diffuse Reflectance) ที่มีข้อมูลทางเคมีของดินอย่างแท้จริง

\section{การวิเคราะห์เชิงเปรียบเทียบแหล่งกำเนิดแสง (Light Emitter)}
โครงการวิจัยได้ทำการศึกษาวิจัยเชิงลึกถึงความเป็นไปได้ในการใช้แหล่งกำเนิดแสง 2 รูปแบบ

\begin{enumerate}
    \item \textbf{การใช้แสงแฟลชจากสมาร์ทโฟน (Smartphone Built-in Flash LED)}
    หลอดแฟลชในสมาร์ทโฟนเป็นหลอด Blue LED เคลือบสารเรืองแสงสีเหลือง (Phosphor-converted White LED) ครอบคลุมเฉพาะย่านแสงขาวที่ตามองเห็น ($450 - 650\text{ nm}$) แต่ไม่มีคลื่นย่านอินฟราเรดย่านใกล้ (NIR $> 700\text{ nm}$) นอกจากนี้ แสงแฟลชสมาร์ทโฟนยังมีปัญหาความร้อนสะสมทำให้ความสว่างลดลง (Thermal Dimming) และอุณหภูมิสีเบี่ยงเบน (CCT Drift) การใช้แฟลชจึงไม่สามารถตรวจวัดพันธะเคมี N-H หรือ Phosphate ได้โดยตรง แต่สามารถใช้ประเมินทางอ้อมผ่านสีของดินและปริมาณอินทรียวัตถุ (Colorimetric Soil Organic Matter Proxy) ซึ่งให้ความแม่นยำ $R^2 \approx 0.78 - 0.85$ เหมาะสำหรับระบบต้นทุนต่ำ (NPxAI Lite)
    
    \item \textbf{การใช้หลอดกำเนิดแสงมัลติสเปกตรัล 7 แถบคลื่น (7-Channel Multi-Spectral LEDs)}
    ระบบวิจัยขั้นสูง (NPxAI Pro) ใช้หลอด LED เฉพาะทางที่เปล่งแสงครอบคลุมความยาวคลื่นวิกฤต 7 ช่วง ได้แก่ $405\text{ nm}$ (Violet), $465\text{ nm}$ (Blue), $525\text{ nm}$ (Green), $630\text{ nm}$ (Red), $850\text{ nm}$ (NIR-1), $940\text{ nm}$ (NIR-2) และหลอด White LED มาตรฐาน (5000K, CRI $> 95$) แต่ละหลอดมีแถบคลื่นแคบ FWHM $< 20\text{ nm}$ ทำให้ระบบสามารถกระตุ้นและวัดการดูดกลืนแสงของพันธะเคมีได้โดยตรง ให้ความแม่นยำสูง $R^2 > 0.90$
\end{enumerate}

\section{แหล่งรับแสงและการปรับเทียบสีมาตรฐาน (Light Detector \& Calibration)}
ระบบใช้เซนเซอร์รับภาพ CMOS ในกล้องสมาร์ทโฟนเป็นตัวตรวจวัดหลัก โดยมีกระบวนการปรับแก้สัญญาณดังนี้

\begin{enumerate}
    \item \textbf{การปรับเทียบด้วยแผ่นเทียบสีขาวมาตรฐาน (White Reference Calibration)}
    ก่อนการสแกนดิน เกษตรกรจะนำแผ่นเทียบสีขาวมาตรฐาน ($\text{BaSO}_4$ หรือแผ่น PTFE บริสุทธิ์ ค่าการสะท้อนแสง $99\%$) บรรจุลงในถาดดิน เพื่อให้ระบบบันทึกความสว่างอ้างอิง $I_{\text{white}}(\lambda)$ สำหรับชดเชยการลดทอนแสงบริเวณขอบเลนส์ (Lens Shading) และการแปรผันของความสว่างหลอดไฟ
    
    \item \textbf{การคำนวณค่าการสะท้อนสัมพัทธ์ (Relative Reflectance)}
    ค่าการสะท้อนแสงของดินคำนวณจากสมการ
    
    \begin{equation}
    R(\lambda) = \frac{I_{\text{sample}}(\lambda) - I_{\text{dark}}(\lambda)}{I_{\text{white}}(\lambda) - I_{\text{dark}}(\lambda)}
    \end{equation}
    
    โดย $I_{\text{dark}}$ คือค่าสัญญาณรบกวนเมื่อปิดไฟมืดสนิท
\end{enumerate}

\section{ข้อกำหนดการพิมพ์สามมิติ (3D Slicing Parameters)}
เพื่อรับประกันความมืดสนิทและการป้องกันแสงสะท้อน การพิมพ์ 3 มิติต้องปฏิบัติตามข้อกำหนดดังต่อไปนี้

\begin{itemize}
    \item \textbf{วัสดุเส้นพิมพ์ (Filament)} พลาสติก PETG หรือ ABS สีดำด้าน (Matte Black) เท่านั้น ห้ามใช้พลาสติกสีขาว สีเทา หรือเส้นที่มีความมันวาว
    \item \textbf{ความหนาผนัง (Wall Loops / Perimeters)} กำหนดอย่างน้อย 4 ถึง 5 รอบ (ความหนาเนื้อพลาสติก $\ge 2.0\text{ mm}$) เพื่อป้องกันแสงทะลุผ่านเมื่อใช้งานกลางแดดจัด
    \item \textbf{ความหนาแน่นโครงสร้างภายใน (Infill)} กำหนด $40\% - 50\%$ โดยใช้ลวดลาย Gyroid ซึ่งช่วยเสริมความแข็งแรงรอบทิศทาง
    \item \textbf{การเคลือบผิวด้านใน (Internal Coating)} พ่นสเปรย์สีดำด้านชนิด Ultra-flat หรือติดกำมะหยี่สีดำภายในกรวยแสงเพื่อดูดกลืนแสงสะท้อนให้เหลือศูนย์
\end{itemize}

\chapter{แบบจำลองปัญญาประดิษฐ์บนขอบ}

\section{การประมวลผลบนขอบแบบ Pure Dart Offline Inference}
แอปพลิเคชัน NPxAI ทำงานแบบออฟไลน์ $100\%$ โดยไม่มีการส่งภาพหรือข้อมูลขึ้นสู่เซิร์ฟเวอร์ภายนอก แบบจำลองปัญญาประดิษฐ์ทั้งหมดถูกสร้างขึ้นด้วยภาษา Pure Dart ทำงานผ่านเอนจินการคำนวณที่ปรับแต่งเฉพาะ (Edge Machine Learning Engine) ทำให้ใช้เวลาประมวลผลน้อยกว่า 50 มิลลิวินาทีต่อการสแกน

\section{การแก้ปัญหาผลการสแกนคงที่ด้วยระบบโมเดลหลายสถาปัตยกรรม}
ในระบบทดสอบเดิม ผลการสแกนแสดงค่าคงที่เนื่องจากโค้ดทดสอบใช้ค่าน้ำหนักคงที่และยังไม่ได้เชื่อมโยงชื่อโมเดลที่ผู้ใช้เลือกเข้าสู่สมการ ทีมวิจัยจึงได้ออกแบบสถาปัตยกรรมแบบจำลองใหม่ 5 โมเดล ซึ่งมีสมการคำนวณ ค่าน้ำหนัก และความสัมพันธ์ทางสเปกตรัมที่แตกต่างกันอย่างสิ้นเชิง ทำให้ผลการสแกนตอบสนองต่อเนื้อดินจริงและสะท้อนจุดเด่นของแต่ละโมเดลอย่างแท้จริง

\begin{enumerate}
    \item \textbf{Model A - CNN-ResNet MobileV3 (Deep Learning Vision)}
    โครงข่ายประสาทเทียมสังวัตนาการ ทำหน้าที่สกัดคุณลักษณะเชิงพื้นที่ ลวดลายเม็ดดิน และการกระจายตัวของสีดิน เพื่อประเมินค่าธาตุอาหารร่วมกับสภาพทางกายภาพ
    
    \item \textbf{Model B - Random Forest Regressor (Soil Color \& SOM Proxy)}
    แบบจำลองกลุ่มต้นไม้ตัดสินใจ (100 Trees) ใช้สีดินในปริภูมิสี CIE $L^*a^*b^*$ และ HSV เพื่อทำนายปริมาณอินทรียวัตถุ เหมาะกับโหมดแสงแฟลชสมาร์ทโฟน
    
    \item \textbf{Model C - ANN Multilayer Perceptron (7-Band Diffuse Reflectance)}
    โครงข่ายประสาทเทียมป้อนตรง 3 ชั้น ทำงานร่วมกับข้อมูลสเปกตรัมทั้ง 7 แถบคลื่น เพื่อจับความสัมพันธ์แบบไม่เป็นเชิงเส้นของการดูดกลืนแสงในพันธะ N-H
    
    \item \textbf{Model D - Support Vector Regression (SVR Non-linear RBF Kernel)}
    แบบจำลองการถดถอยเวกเตอร์สนับสนุนด้วยฟังก์ชันเรเดียล เหมาะสำหรับ Available P ซึ่งมีลายนิ้วมือสเปกตรัมซับซ้อนในดินกรด
    
    \item \textbf{Model E - Partial Least Squares Regression (PLSR Baseline Chemometrics)}

\chapter{สถาปัตยกรรมแอปพลิเคชันและการจัดการดินแม่นยำ}

\section{การปรับปรุงแอปพลิเคชัน Flutter เวอร์ชัน 1.2.0}
แอปพลิเคชันได้รับการปรับปรุงสถาปัตยกรรมอินเทอร์เฟซเพื่อให้สอดคล้องกับสภาพการทำงานจริงในแปลงเกษตรกรรม

\begin{itemize}
    \item \textbf{ระบบพิกัด GPS อัตโนมัติ} แสดงผลพิกัดละติจูดและลองจิจูดในบรรทัดเดียวกัน พร้อมระบุทิศทางภูมิศาสตร์สากล (N/S/E/W) เช่น \texttt{12.613725° N | 102.103862° E}
    \item \textbf{ชุดปุ่มควบคุมการบันทึก 3 รูปแบบ} จัดวางปุ่มคำสั่งสำคัญไว้กึ่งกลางหน้าจออย่างชัดเจน ประกอบด้วย ปุ่มสแกนวิเคราะห์ดิน (Scan), ปุ่มบันทึกภาพถ่าย (Photo Capture) สำหรับจัดเก็บคลังข้อมูลภาพดิน และปุ่มบันทึกวิดีโอ (Video Record)
    \item \textbf{ป้ายกำกับโมเดลแบบไดนามิก (Dynamic Model Selector Badge)} แสดงชื่อโมเดลที่กำลังทำงานอย่างชัดเจน และปรับเปลี่ยนผลการทำนายทันทีเมื่อผู้ใช้งานสลับโมเดล
    \item \textbf{การ์ดแสดงผลธาตุอาหารแบบ Unclipped} ปรับแก้โครงสร้างคอนเทนเนอร์ให้แสดงผลครบถ้วนสมบูรณ์ ไม่มีการตกขอบหรือตัวอักษรล้นจอในทุกขนาดหน้าจอสมาร์ทโฟน
\end{itemize}

\chapter{ซอร์สโค้ดแบบจำลองปัญญาประดิษฐ์บนขอบ}

\begin{dartcode}[เอนจินการคำนวณแบบจำลองปัญญาประดิษฐ์หลากสถาปัตยกรรม (Pure Dart)]
class MultiModelEdgePredictor {
  // Multi-Model Edge Inference Switching
  NutrientPrediction predict({
    required SpectralSignature signature,
    required AiModelType modelType,
  }) {
    switch (modelType) {
      case AiModelType.cnnResNet:
        return _predictCnnResNet(signature);
      case AiModelType.randomForest:
        return _predictRandomForest(signature);
      case AiModelType.annPerceptron:
        return _predictAnnPerceptron(signature);
      case AiModelType.svrRbf:
        return _predictSvrRbf(signature);
      case AiModelType.plsrChemometrics:
        return _predictPlsr(signature);
    }
  }

  NutrientPrediction _predictAnnPerceptron(SpectralSignature sig) {
    final List<double> x = sig.toFeatureVector();
    double nSum = -0.42;
    for (int i = 0; i < x.length; i++) nSum += x[i] * _annWeightsN[i];
    final double predN = 0.45 + (2.65 / (1.0 + exp(-nSum * 0.82)));

    double pSum = 3.8;
    for (int i = 0; i < x.length; i++) pSum += x[i] * _annWeightsP[i];
    final double predP = max(2.5, pSum);

    return NutrientPrediction(
      totalNitrogen: predN,
      availablePhosphorus: predP,
      confidenceScore: 0.945,
    );
  }
}
